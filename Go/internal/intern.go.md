# File: intern.go

intern.go文件位于Go语言源码中的/internal目录下，它的作用是用于代码的字符串常量池来提高代码的执行速度和节省内存消耗。具体来说，它主要提供了字符串常量池的实现，包括字符串的创建、查询和共享等操作。

在Go语言中，每个字符串都是一个独立的对象，如果代码中存在相同内容的字符串，那么它们也会分别占用内存空间。为了避免重复创建相同的字符串对象，intern.go文件提供了一个字符串池，它会保存已经创建过的字符串对象，并在需要时直接返回共享的对象，从而节省内存消耗。

具体来说，intern.go文件中定义了一个字符串池的结构体（sharedPool），它包含一个字符串到对象的映射表，并提供了以下方法：

- func (p *sharedPool) Get(s string) string：根据给定字符串s返回对应的共享对象，如果没有该字符串，则创建新的字符串对象并放入映射表中，然后返回该对象。
- func (p *sharedPool) Put(s string)：将给定字符串s放入映射表中，如果映射表中已经存在该字符串，则不进行任何操作。

通过这些方法，可以确保代码中相同内容的字符串只被创建一次，并且可以在不同的代码区域中共享使用。这样可以有效降低内存消耗，并提高代码的执行效率。

总之，intern.go文件是Go语言内部的一个实用工具，它提供了字符串常量池的基础功能，为代码的执行效率和内存使用提供了重要的帮助。

### intern

在Go语言中，字符串（string）是常用的数据类型之一。当我们声明一个字符串时，Go语言会在运行时为该字符串分配内存并返回一个指向该字符串的指针。然而，在一些场景下，我们需要多次使用相同的字符串，而每次都重新分配内存会浪费空间和时间。因此，Go语言提供了一个名为intern的字符串池（string pool）机制，将已经分配的字符串存储在共享的内存池中，并返回指向该池中字符串的指针，避免多次分配相同的字符串。

实现这个字符串池机制的核心就是intern变量。该变量是一个字符串到字符串指针的映射表（map），用于存储已经分配过的字符串，其key为字符串内容，value为字符串指针。当我们创建一个新的字符串时，首先会按照字符串内容在池中查找有无相同的字符串，如果存在则返回其指针，如果不存在则新分配内存，并将其存入池中。

除了能够提高内存利用率和加速字符串查找外，intern变量还有一个重要的作用：它维护了字符串到字符串指针的唯一映射。在Go语言中，两个字符串即使内容相同，也可能由于分配内存的地址不同而不相等。因此，如果你使用的是不同的字符串指针，你需要使用等于号（==）进行比较，而不能使用字符串比较函数（如strings.Equal、strings.Compare等）。在这种情况下，我们可以通过在字符串池中查找已经分配的字符串来确保唯一性，而不受分配内存地址的影响。

综上所述，intern变量在Go语言中实现字符串池和字符串唯一性映射的核心作用。

### key

在 Go 语言中，`key` 结构体是一个内部使用的结构体，用于存储字节数组。它的定义如下：

```
type key struct {
	bytes []byte
	hash  uint32
}
```

主要有两个字段：

- `bytes` 字段是一个字节数组，用于存储字符串的字节序列。
- `hash` 字段是一个无符号整数，表示存储在 `bytes` 字段中字符串的哈希值。

`key` 结构体的作用是在 Go 语言中实现字符串池（interning）。字符串池是一种存储字符串的技术，它避免了重复的字符串被存储多次，从而减少了内存的使用。具体来说，字符串池会维护一个存储字符串的集合，在集合中只保存唯一的字符串，其他重复的字符串都通过引用来访问池中已有的字符串。

在 Go 语言中，字符串池是通过 `map[key]string` 来实现的。`key` 结构体用于作为 `map` 的键值，这样可以保证字符串在存储时是唯一的，而不是使用多个相同的字符串对象。同时，由于字符串的比较操作比字节序列（byte slice）的比较操作要慢，所以 `key` 结构体中保存了字符串的哈希值，可以通过哈希值快速定位字符串是否已经存在于字符串池中。

### safeMap

在Go语言的并发编程中，访问共享数据时会面临锁的问题，锁的使用会影响程序的性能和可维护性。为了避免使用锁，可以利用Go语言的map类型的并发读写特性实现一个并发安全的map，即safeMap。

safeMap是一个并发安全的map，它的作用是用于在多个goroutine之间安全地共享数据。safeMap通过使用sync包中的RWMutex来保证并发读写的安全。safeMap可以支持任何类型的值，而不仅仅是字符串和数值类型。

在intern.go中，safeMap是用于存储interned字符串的，interned字符串是指在Go语言中多个字符串变量指向相同字符串字面量时，它们共享相同的内存空间，这样可以避免相同的字面量重复占用内存空间。

具体来说，safeMap实现了以下几个方法：

1. Store(key Key, value Value)

存储键值对，如果键已经存在，则更新对应的值。

2. Load(key Key) (value Value, ok bool)

读取指定键的值，如果值存在则返回值和true，否则返回nil和false。

3. LoadOrStore(key Key, value Value) (actual Value, loaded bool)

读取指定键的值，如果值存在则返回值和true，否则存储给定的键值对，并返回给定的值和false。

4. Range(f func(key Key, value Value) bool)

遍历safeMap中所有的键值对，并调用f方法处理每个键值对。

在使用safeMap时，需要注意的是，如果值是引用类型，则需要自行保证并发访问的安全，因为safeMap只能保证键值对的并发读写是安全的，而不能保证值本身并发访问的安全。



### GetByString

GetByString函数是在Go语言的内部包（internal）中定义的，其作用是将一个字符串转换为一个intern.String类型的值。

intern.String是一个自定义类型，在intern包中有定义：

```go
type String struct {
    str  string
    hash uint32
}
```

可以看到，intern.String包含两个字段，其中str是实际的字符串值，而hash是str的哈希值。可以看到，intern.String实际上是一个字符串的包装器。

GetByString函数的实现逻辑如下：

首先，将要查找的字符串计算出哈希值。

然后，遍历已有的intern.String对象列表，查找哈希值是否相同，如果相同，则比较实际字符串值是否相同，如果也相同，则返回这个intern.String对象。

如果没有找到相同的intern.String对象，则创建一个新的intern.String对象，并添加到列表中。

这个函数的作用是尽可能地避免重复字符串的创建和使用，从而提高Go程序的性能。在Go语言中，字符串在运行时是不可变的，因此如果有大量重复的字符串创建，会导致内存占用和垃圾收集负担增加，降低程序的性能。GetByString函数就是为了解决这个问题而设计的。

### finalize

在 Go 语言中，`finalize` 函数是 GC（垃圾回收）机制的一部分。当一个对象不再被程序引用时，垃圾回收器会将其标记为垃圾并在一定时间后将其从内存中释放。然而，有些对象需要执行一些特定的操作才能被正确地释放。`finalize` 函数就是为了在垃圾回收器释放对象之前，执行这些特定操作的函数。

在 `intern.go` 文件中，`finalize` 函数的作用是将当前对象中尚未被使用的字符串重新添加到字符串池中，以便在之后的程序执行过程中重复使用这些字符串。这个操作可以降低内存开销，提高程序的性能。

具体而言，`finalize` 函数会遍历当前对象中的所有字符串，并将它们添加到字符串池中。在添加字符串之前，它会检查字符串是否已经在池中，如果已经存在则不添加。这个操作可以避免重复的字符串在池中出现，从而节省内存。

总之，`finalize` 函数在 Go 语言中扮演着非常重要的角色，它确保了在对象被释放之前执行特定的操作，从而提高了程序的性能和稳定性。
