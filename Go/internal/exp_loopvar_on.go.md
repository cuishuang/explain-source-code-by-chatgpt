# File: exp_loopvar_on.go

exp_loopvar_on.go文件的主要作用是启用循环变量捕获功能的实验特性。

循环变量捕获是Go语言中一种常见的特性，它允许在循环中使用闭包来捕获循环变量的值。例如，下面的代码会打印10个数字1，而不是从0到9：

```
for i := 0; i < 10; i++ {
    go func() {
        fmt.Println(i)
    }()
}
```

这是因为闭包中捕获的是变量i的地址，而在循环执行过程中i的值是一直变化的。因此，在所有goroutine都启动之前，循环已经完成，并且i的值已经变成了10。因此，所有的goroutine都会打印出10。

为了解决这个问题，Go语言引入了循环变量捕获功能，可以在循环中为每个迭代创建一个新的变量。以下是使用循环变量捕获功能的代码：

```
for i := 0; i < 10; i++ {
    i := i // 创建一个新的变量i
    go func() {
        fmt.Println(i)
    }()
}
```

在此代码中，我们在每个迭代中创建一个新的变量i，并将其初始化为当前的i的值。此时，在每个goroutine中使用的是不同的变量i，因此每个goroutine将输出不同的数字。

exp_loopvar_on.go文件为这个功能添加了一个实验特性标签，这意味着在使用该功能时需要小心处理并经过测试，因为该特性可能会在将来的版本中进行更改。
