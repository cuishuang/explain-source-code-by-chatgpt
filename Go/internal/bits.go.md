# File: bits.go

bits.go文件是Go语言的一个内部包，用于对比特位进行相关操作，包括将一个字节序列按位分割、截取、翻转和反转等操作。该包主要用于一些底层的二进制操作，比如在处理网络协议数据时，在对数据进行序列化和反序列化过程中需要对二进制数据进行位操作，这时就可以使用bits包提供的功能。

bits包提供了以下几个主要函数：

1. ReverseBytes用于翻转字节序列。当需要将一个整数从大端序转化为小端序或者从小端序转化为大端序时，可以使用此函数操作字节序列，从而实现整数的字节序转化。

2. MulUint64用于计算无符号整数的某个位与2的幂次方的乘积。例如，可以使用此函数计算2的n次方的值，从而避免使用乘法操作，提高运算效率。

3. TrailingZeros用于获取一个无符号整数低位的连续零位数。该函数可以用于计算一个数x表示为2的幂次方的形式，即x=2^n。这在性能优化中有很多用途。

4. BitLen用于返回一个无符号整数的位数。可以用于计算一个整数需要多少位二进制位才能表示。

5. RotateLeft和RotateRight用于循环左移和循环右移操作。当需要对一个无符号整数进行循环左移或循环右移时，可以调用这两个函数。

总之，bits.go文件中的函数主要用于位操作，可以实现一些底层的二进制计算。它们可以大大提高代码的效率，以及写代码时的便利性。

### block

在 Go 语言里，bytes 包中比特位操作所使用的 block 结构体定义在 bits.go 文件中，并提供了一些有用的方法。

block 结构体是一个表示连续比特位序列的数组，它被用作具体比特截断类型（Concrete bit truncation types）。该块是一个 unsigned uint64 的数组，每个元素都包含 64 个比特。

具体来说，block 结构体的作用如下：

1. 提供对比特位按单一或多个位置设置和清除的方法。

2. 提供对比特位之间移位（旋转）操作的方法。

3. 提供常规算术和逻辑运算的方法。

4. 简化位序列的操作。

5. 提高执行效率。

总的来说，block 结构体在 Go 语言中用于进行比特位操作，为开发人员提供了一些有用的方法，使其操作更加便捷、高效。



### bitReader

bitReader是在Go语言的标准库中，位操作的辅助结构体，具体作用是实现对字节序列的位操作读取。

具体来说，帮助读取二进制数据字节中的每一个 bit（位）信息，并根据需要提供方法 setpos 或步进位（skip）。在读取字节流时，bitReader常常用于解压缩或者解密数据，并可以与底层的字节流或者缓存进行集成。

在bits.go文件中，bitReader结构体主要实现了以下几个方法：

1. readBit() bool：读取并返回当前位置的下一个比特位；
2. readByte() byte：读取下一个字节；
3. setpos(pos int)：设置读取位置（pos即为读取的字节数）；
4. skip(count uint)：跳过指定数量的比特位；
5. byteAlign()：对齐到下一个比特边界；
6. reverseByteOrder(data []byte)：反转字节顺序。

在实现解压缩或加密算法时，bitReader结构体是非常有用的。



### reverseBitReader

reverseBitReader结构体是一个带有缓冲区的位反转读取器，它的主要作用是将字节流中的位序列反转顺序，即将最高位转换为最低位，次高位转换为次低位，以此类推。在大多数情况下，字节流的位序列按照顺序排列，但有些文件格式（例如PNG图像文件）需要将位序列反转以便解析。reverseBitReader结构体可以轻松地实现这个功能。

reverseBitReader结构体包含以下字段：

- r：一个io.Reader接口，用于读取字节流。
- buf：一个缓冲区，用于将读取的字节转换为位序列并反转顺序。
- pos：一个当前位的位置指针，用于跟踪缓冲区中的下一个位。

reverseBitReader结构体还实现了以下方法：

- ReadBit：从缓冲区中读取下一个位。该方法返回一个bool值，表示读取的位是0还是1。如果缓冲区已满，则会读取更多字节并添加到缓冲区中。
- ReadBits：从缓冲区中读取指定数量的位。该方法返回一个uint32值，表示读取的位的值。如果缓冲区中没有足够的位，则会读取更多字节并添加到缓冲区中。
- Seek：将当前位的位置指针移动到指定位置。

通过使用reverseBitReader结构体，开发者可以方便地读取反转顺序的位序列，并避免了手动反转位序列所需要的复杂操作。因此，reverseBitReader结构体对于解析需要反转位序列的文件格式非常有用。

### makeBitReader

makeBitReader函数是用于创建一个新的bitReader对象的函数。bitReader用于读取比特流。

在makeBitReader函数中，参数data是一个字节数组，表示要读取的比特流。参数nBits是一个整数，表示比特流的位数。

这个函数返回一个新的bitReader对象，该对象包含以下属性：

1. data []byte：表示要读取的比特流。

2. nBits int：表示比特流的位数。

3. r BitsReader：表示位读取器，用于从比特流中读取位。

在初始化完成后，使用bitReader对象的ReadBit方法可以从比特流中读取一个比特。每次调用ReadBit方法将从比特流中读取下一个比特，并将其作为一个bool类型的值返回。如果已经读取完了比特流，则ReadBit方法将返回-1。

因此，makeBitReader函数的作用在于创建一个新的bitReader对象，并将需要读取的比特流以及比特流的位数传递给该对象。



### moreBits

在Go语言的标准库中的`bits.go`文件中，`moreBits`这个函数的作用是计算x所需的比特数。具体来说，当x大于0时，该函数返回`log2(x) + 1`。当x小于或等于0时，该函数返回1。

此函数的主要作用是计算一个整数的比特位数，比如在实现一些位操作时可以用到。其实现过程比较简单，首先用log2函数计算x的对数，然后将其向上取整再加1即可。如果x为负数或零，则返回1。

下面是`bits.go`中的`moreBits`函数的代码实现：

```go
func moreBits(x uint) int {
    if x == 0 {
        return 1
    }
    return int(Log2(x)) + 1
}
```

注：上面的Log2函数是另一个函数，用于计算x的以2为底的对数，它的实现如下：

```go
// Log2 returns the integer logarithm base 2 of x.
// The result is undefined for x <= 0.
func Log2(x uint) uint {
    return uint(bits.Len(x) - 1)
}
```



### val

在go/src/internal/bits.go文件中，val函数映射了一个64位以上的整数的每个1位的位置到一个字节数组中。它的作用是返回一个slice，其中每个元素表示相应位的1的位置。对于被映射的整数，左数第i位的位置被存在slice中的第i个元素中。

例如，如果val(0x110)被调用，它将返回一个长度为2的slice，其中的元素为[0, 4]。这是因为0x110在二进制中被表示为0001 0001 0000，即第0和第4位都是1。因此，slice中的前两个元素的值分别为0和4。

该函数尤其有用在处理二进制掩码中的位操作时。



### backup

在Go语言的`go/src/internal`包中，`bits.go`文件中的`backup`函数是用来将一个64位整数的最高位设置为1并返回结果的函数。

该函数的定义如下：

```
func backup(x uint64) uint64 {
    x |= x >> 1
    x |= x >> 2
    x |= x >> 4
    x |= x >> 8
    x |= x >> 16
    x |= x >> 32
    return x
}
```

该函数会将输入参数`x`的最高位之后的所有位都设置为1，从而保证了输入参数`x`在二进制中至少有一位为1。

通过这个函数，我们可以轻松地获取一个大于等于输入参数`x`的最小的2的幂次方整数。例如，`backup(3)`函数返回的是4，`backup(13)`返回的是16。

在一些算法实现中，我们需要将输入的数据调整为2的幂次方的形式，而这个函数可以方便地帮我们实现这个操作。

### makeReverseBitReader

makeReverseBitReader是一个函数，它的作用是创建一个逆序读取位的位模式读取器。在计算机中，数字是以二进制形式存储的，通常称为位模式，其中每个二进制位代表一个数字的一部分。例如，数字7的位模式是111，而数字10的位模式是1010。

在某些情况下，需要逆序读取二进制位，例如在解码压缩文件时。makeReverseBitReader函数创建的读取器可以读取这些反向位模式，并将其转换回正向顺序，以便进行适当的解码。

这个函数的实现过程比较复杂，它使用了底层的位运算来处理位模式的反向读取。具体来说，函数使用一个字节数组来存储要读取的位模式，并且使用两个指针来跟踪当前读取的位和未读取的位。每当要读取一个位时，函数将使用位掩码运算来获取二进制位的值，并将指针向前移动。读取器还可以处理字节序列，以便正确处理多字节值的读取。

总之，makeReverseBitReader函数在内部实现中使用了底层位运算来创建一个反向位模式读取器，可以处理反向位模式，将其转换为正向顺序进行适当的解码。



### fetch

fetch函数是在bits.go文件中定义的，它的作用是从输入字节流中读取指定数量的位，将它们解析为一个uint64类型的值并返回。该函数的形式参数r是一个io.ByteReader类型的接口，它表示实现了ReadByte方法的对象，因此可以像读取字节一样读取位。参数n指定从输入流中读取的位的数量，如果n超过64，则只读取最低的64位，高位会被忽略。如果读取的位数不足64位，则未读取的位被视为0。

fetch函数在解析二进制格式的文件时经常被使用。例如在解析ELF格式（一种常见的可执行文件格式）时，ELF头部中的各种字段都是按照位存储的。因此，我们需要使用fetch函数来读取这些字段的值。另外，fetch函数还被用于计算32位和64位哈希值的算法中，例如MurmurHash算法。在这种情况下，对输入的指定长度的位进行哈希计算。
