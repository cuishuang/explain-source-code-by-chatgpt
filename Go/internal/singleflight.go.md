# File: singleflight.go

go/src/internal/singleflight/singleflight.go 是 Go 语言中用于管理函数请求共享同一结果的库。在 Go 语言中，单例模式指的是在相同函数的多次调用之间共享同一结果。SingleFlight 可以让我们在多个协程之间共享结果，提高程序的性能。

SingleFlight 的核心是一个中心控制器，用于管理请求共享和状态转移。在这个中心控制器中，每个Request都是唯一的，每个Request又包含了若干的Caller。

SingleFlight 中还有一个互斥锁 Mutex，用来保证在进行状态转移时的同步性。当一个请求到来时，如果请求已存在，则直接返回请求结果；如果请求不存在，则将请求放入中心控制器中，执行请求之前，会对Mutex进行加锁；然后执行请求，将结果返回；最后对 Mutex 解锁。

SingleFlight 库的使用非常简单，只需通过 NewGroup 函数创建一个 Group 对象，通过 Group.Do 函数即可在多协程之间共享函数返回值。

总之，SingleFlight 可以优化系统中某些性能问题，尤其擅长优化同一个请求在高并发情况下的情况，是一个非常实用的库。

### Structs:

### call

call这个结构体在singleflight.go文件中用于表示一个正在进行中的函数调用，并且这个调用尚未完成。它具有以下不同的属性：

1. Key：表示该调用的键值，通常是一个字符串或者一个[]byte类型的片段。
2. Done：表示是否已经完成该调用。
3. Err：表示调用执行过程中是否产生了错误。
4. Value：表示调用执行的结果，通常是一个interface{}类型的值。
5. Ch：表示完成这个调用任务的通道。

在singleflight中，如果多个goroutine同时调用了同一个Key的函数，则只有一个goroutine会真正执行并返回结果，其他goroutine直接等待结果即可。这种技术称为“缓存”的singleflight实现，可以提供短暂的延迟和消除冗余请求的好处。

call结构体可以让singleflight有效地处理缓存和等待状态，并最终返回所有并发请求的单一结果。call是singleflight的核心组件，它充分发挥了缓存的潜力，并提供了最终结果的准确通知。



### Group

Group结构体是用来管理和维护缓存中数据的。

具体来说，Group结构体通过一个共享的互斥锁来避免资源竞争，并提供了一个map数据结构用来存储和管理缓存中的数据。此外，Group结构体还封装了一个sync/singleflight.Group类型的实例，用于缓存中热点数据的获取和管理。

在实际应用中，Group结构体可以根据不同的业务场景和需求来创建不同的缓存实例，从而实现高效、灵活的数据管理和访问。



### Result

Result是singleflight包中的一个结构体，它的作用是用来存储单次请求的结果。

singleflight是一个用来避免重复请求的包，为了避免重复请求，这个包使用了sync.Mutex实现了锁控制。当发起请求时，如果缓存中已经有了结果，则直接返回缓存结果；如果没有缓存结果，则将请求加入到一个map中，然后在请求执行完成后再将结果存储到缓存中。

当一个请求被缓存时，会使用Result结构体来存储请求结果。这个结构体包含三个字段，分别是：

1._val：存储请求结果的值
2.err：存储请求过程中遇到的错误
3.ch：用来通知正在等待结果的请求

当单次请求执行完成后，会将结果存储在Result结构体的_val和err字段中，并通过ch通知正在等待结果的请求。这样，一旦有其他请求发起相同的请求，就可以直接返回缓存中的结果，而不用再次执行请求。这个方法可以有效地减少重复请求，提高程序的性能。

总的来说，Result结构体是用来存储singleflight包中每个请求的结果的，它通过_val和err字段来存储请求结果，通过ch通知其他请求获取结果。



## Functions:

### Do

Do函数是singleflight包中最核心的函数，它的作用是在请求并发到来时，保证只有一个请求会被发送，而其余的请求将得到等待中的响应。在完成第一个请求后，其余等待中的请求可以获取到第一个请求返回的结果，从而避免了重复的计算和请求。

具体来说，Do函数的实现维护了一个请求队列，当同样的key在短时间内多次访问时，只有第一个请求会执行，其余请求将会等待第一个请求完成后返回其结果。Do函数的返回值是一个Result类型的结构体，其中包含了请求的结果和错误信息。

除了Do函数，singleflight包还提供了两个函数：DoChan和Forget。DoChan函数和Do函数的功能类似，不过它不会阻塞，而是使用一个通道进行异步发送请求，并且返回一个通道，当结果可用时会通过该通道通知接收者。Forget函数则是用于清除所有等待中的请求，可以在某些场景下用于释放不必要的请求等待。



### DoChan

DoChan是Go语言中内部包singleflight中的一个函数，它用来执行一个函数并返回它的结果，如果这个函数被多次调用，DoChan只会执行一次，并且其他调用会等待原始调用返回结果。DoChan函数的内部实现使用了通道（chan），这样可以方便地控制调用间的并发。

DoChan的函数签名如下：

```
func (g *Group).DoChan(key string, fn func() (interface{}, error)) <-chan Result
```

其中，key是用来标识需要执行的函数的唯一键，fn是需要执行的函数，返回一个包含结果和错误的元组（tuple），而返回值是一个只读通道（channel），用来读取fn的执行结果。

DoChan的具体实现流程：

1. 判断是否已经有其他调用正在执行fn，如果有，就直接返回等待结果的通道。
2. 如果fn没有被调用，就准备一个等待结果的通道。
3. 将这个等待结果的通道存入通道缓存中，这样其他调用就可以获取到这个通道并等待结果。
4. 执行fn并获取结果，把结果存储在缓存中。
5. 从缓存中获取这个结果，并通知所有等待结果的通道返回结果。
6. 返回通道，让调用者可以读取结果。

DoChan的作用是避免进行重复的计算，提高系统性能，同时也避免了传统的锁机制可能带来的死锁等问题。



### doCall

在singleflight.go文件中，doCall函数的作用是执行被请求的函数fn。如果fn返回错误，则将其保存在call结构中并返回错误。如果成功，则将结果保存在call结构中，并将结果返回。因此，doCall函数负责执行实际的请求，并处理错误和结果，并根据情况将它们保存在call结构中。

代码实现中，doCall函数首先从函数执行缓存中检索与请求关联的请求。如果找到缓存，则返回缓存中的结果。如果没有，则创建一个新的请求，并将其保存在函数执行缓存中。然后，doCall函数调用请求的fn函数，并检查是否发生任何错误。如果没有，则将结果保存在请求的结果字段中，并将结果返回。如果发生错误，则将该错误保存在请求的错误字段中，并将错误返回。

总之，doCall函数是Singleflight实现中的核心功能之一，负责执行请求并处理错误和结果。它使用函数执行缓存来避免多余的请求，并为每个请求创建一个请求缓存来保持跟踪请求的状态和结果。



### ForgetUnshared

函数ForgetUnshared() 在singleflight.go文件中的实现，其主要作用是从共享池中移除指定的key。Singleflight 共享池是一种用于消除重复请求的机制，以确保同一时刻只有一个请求发送到后台，以避免繁重的计算或资源调用的重复成本。当多个Goroutine尝试获取共享池中同一key的值时，共享池只会执行一次请求，同时将结果分发给所有的等待请求。这样可以降低系统的负载压力，提高性能。

ForgetUnshared() 函数接受一个 key 作为参数，函数的作用是从共享池中移除该 key。这个函数通常是在单个请求结束后立即调用，以保持共享池的内存使用量的稳定，避免不必要的内存泄漏。如果一个 key 被移除了，那么下一次请求将重新发起一次请求，而非从共享池中获取结果。

总之，ForgetUnshared() 函数是 Singleflight 共享池机制的一个附加功能，它可以帮助我们在使用 Singleflight 共享池时，更好地管理内存使用量，避免不必要的资源浪费，并提高程序性能。
