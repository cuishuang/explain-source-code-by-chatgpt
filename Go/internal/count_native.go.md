```
func Count() int {
    n := int32(runtime.NumCPU())
    if n > 1 {
        n -= 1
    }
    return int(n)
}
```

该函数首先使用`runtime.NumCPU()`函数获取CPU的核心数量，并将结果存储在变量`n`中。如果核心数量大于1，则从`n`中减去1以反映实际可用的核心数量（剩下的一个核心由进程管理器使用）。最后，函数返回可用的CPU核心数量。

该函数通常用于内部优化或测试目的。它非常简单，只是返回可用的CPU核心数量，因此很容易理解和使用。

### countGeneric
