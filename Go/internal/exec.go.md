# File: exec.go

go/src/internal/exec.go文件实现了一个辅助函数go/exec包中的运行命令的函数。 

该函数在系统中运行一个新的进程，并等待该进程的退出。其主要流程如下：

1. 使用os/exec库启动一个新的进程并将命令与参数传递给该进程
2. 根据系统情况，开启进程所需的文件描述符等
3. 等待执行的进程完成其执行，并将进程的状态返回

写这个文件的目的是为了提供一个更通用的和有足够控制的函数来执行命令，以满足更复杂的使用情况和更高级的需求，尤其是对于一些需要控制进程执行的子进程的程序。同时，这个文件也能帮助Go语言实现更高级别的命令行工具。

### Var:

### tryExecOnce

变量 `tryExecOnce` 在 `exec.go` 文件中的作用是控制单次执行 `exec()` 函数的行为。

`tryExecOnce` 是一个布尔值，默认值为 false。如果该变量为 true， 则 `Exec` 函数仅尝试一次调用 `exec()`。 如果调用失败，则不会进行重试。 如果该变量为 false，则 `Exec` 函数将尝试多次调用 `exec()`， 直到成功或达到最大重试次数为止。

在执行 `exec.Command()` 命令时，不可能保证每次调用都能成功执行，例如系统资源不足或程序崩溃等情况。如果想在尝试重新执行前，允许等待操作系统分配资源给进程，可以将 `tryExecOnce` 设置为 false，这将允许 `exec()` 函数多次尝试执行命令。

如果设置成 true，则只会执行一次，这可以在调用之前测试命令是否存在或特定权限是否满足的情况下使用，以避免多余的重试。但是如果 `tryExecOnce` 为 true，命令将不被重试执行，这可能会导致不必要的失败。

综上所述， `tryExecOnce` 的作用是在调用 `exec()` 函数时为 `Exec` 函数提供附加的控制选项，可以根据需要将其设置为 `true` 或 `false`。



### tryExecErr

变量tryExecErr定义在exec.go文件中，作用是在调用exec.LookPath函数时获取任何错误返回。

exec.LookPath函数在系统的PATH环境变量中搜索可执行文件并返回绝对路径。如果该函数即在尝试系统路径后，仍无法发现可执行文件，则该函数将返回一个错误。tryExecErr变量被用来捕获此错误并在exec.Command函数调用之间传递，以便在找不到可执行文件时立即返回错误，并避免执行不必要的系统调用。 

在tryExecErr变量的定义中，它被初始化为nil，即不存在错误。当扫描PATH路径时，如果exec.LookPath函数检测到错误，则tryExecErr变量将被设置为该错误，稍后在exec.Command函数中检查这个值，如果tryExecErr不为空，则直接返回该错误，以提高程序的执行效率。



### execPaths

在 Go 语言中，execPaths 是一个字符串切片，它包含了一些可执行文件的路径。这些可执行文件通常是一些系统自带的命令行工具，比如 ls、cp、mv 等等。

execPaths 变量的主要作用是在使用 exec.Command 函数时用来寻找要执行的命令。当我们在使用 exec.Command("foo") 时，Go 语言会到 execPaths 数组中查找相应的可执行文件。

如果数组中的某个路径可以找到对应的可执行文件，那么该可执行文件就会被执行。否则，exec.Command 函数会返回一个错误，告诉我们找不到对应的命令。

需要注意的是，execPaths 变量只能在程序初始化时使用。也就是说，我们不能在程序运行时修改 execPaths 数组的内容。如果我们需要在运行时寻找新的可执行文件，必须手动指定该文件的绝对路径。



## Functions:

### MustHaveExec

MustHaveExec是go/src/internal/exec包中的一个函数，作用是检查当前系统是否有可执行文件。如果找不到可执行文件，则会出现一个致命错误并中止程序执行。

该函数接受一个可执行文件名作为参数，并在系统PATH中寻找该文件。如果找到了该文件，则返回其路径，否则会出现一个致命错误并中止程序执行。

该函数主要用于确保在需要执行特定操作的程序中，必须确保某些可执行文件存在，否则程序无法正常工作。例如，在某些操作需要使用某种命令行工具的程序中，这个检查可确保程序运行时不会因为缺少必要的工具而崩溃。

总之，MustHaveExec是一个非常有用的函数，可以确保执行程序的可靠性和稳定性。



### tryExec

tryExec函数是在exec.go文件中，负责执行指定的可执行程序的函数。

当我们调用exec.Command()时，它会返回一个*exec.Cmd结构体的指针，其中包含了一个用于执行命令的Run()方法。而Run()方法实际上就是调用了tryExec()函数来执行指定的可执行程序。

tryExec()函数接收两个参数：要执行的命令和命令的参数。它首先会查找这个命令在系统中的绝对路径，如果找到了就直接执行；如果没有找到，则遍历$PATH环境变量中的每个路径，直到找到为止。如果最终没有找到，就返回一个错误信息。

tryExec()在执行命令时，会将环境变量设置为当前系统的环境变量，但是它还支持在命令执行时添加自定义的环境变量。用户可以在Command结构体中设置Env字段来传递自定义环境变量。

如果命令执行成功，tryExec()会返回nil；否则返回一个带有错误信息的*ExitError结构体。

总之，tryExec函数是exec包中最核心的函数之一，它实际上就是一个封装了系统调用的函数，用于执行指定的命令。



### MustHaveExecPath

MustHaveExecPath是一个函数，检查给定的可执行文件名是否存在并可执行，并返回文件名。如果文件不存在或无法执行，则会panic。

该函数的作用是确保给定的可执行文件名存在并可执行，以便在程序运行时使用。如果文件不存在或无法执行，则程序可能会失败或出现未定义的行为。因此，使用MustHaveExecPath可以帮助程序员在程序运行之前发现问题，并及时修复。

在实现上，该函数会检查给定的可执行文件名是否是一个可执行文件，并可以读取和执行该文件。如果是，则返回文件名；否则，抛出panic。需要注意的是，这个函数只检查文件是否存在并可执行，而不会检查该文件的其他权限或安全性问题。因此，在使用MustHaveExecPath时，程序员仍然需要自己考虑文件的权限和安全性问题。



### CleanCmdEnv

CleanCmdEnv函数的作用是清理命令执行所需的环境变量，例如PATH、LD_LIBRARY_PATH和DYLD_LIBRARY_PATH等。这些环境变量可能会影响命令的执行结果，因此需要将它们从环境中移除。具体来说，该函数会将以下环境变量从环境中移除：

1. PATH：包含可执行文件的目录列表
2. LD_LIBRARY_PATH（在Linux上）和DYLD_LIBRARY_PATH（在macOS上）：包含共享库所在的目录列表

此外，该函数还会将一些与安全有关的环境变量从环境中移除，以避免安全漏洞。例如，LD_PRELOAD（用于指定预装载共享库的列表）和LD_DEBUG（用于控制动态链接器的调试输出）都可能被滥用为攻击手段，因此需要将它们从环境中移除。

总之，CleanCmdEnv函数可以确保命令执行时的环境变量与当前进程环境的保持一致，从而消除环境变量对命令执行结果的影响，并提高命令执行的安全性。



### CommandContext

CommandContext是Go标准库中exec包的一个函数，用于创建一个指向命令的结构体，即Cmd类型的变量，其作用是在指定的上下文中运行命令。它接受一个Context类型的参数，该参数用于控制命令的执行，例如取消命令、设定执行超时等。

具体来说，CommandContext函数会返回一个指向Cmd类型的指针变量，该类型的结构体包含了命令的名称、参数、环境变量等信息，并且还有一些控制命令执行的属性，例如工作目录、标准输入输出的重定向方式等。通过调用Cmd变量的方法或属性，我们可以控制和监管命令的执行过程。

执行命令的过程是异步的，CmmandContext函数的返回结果不会等待命令执行的完成，如果需要等待命令执行结束，可以调用Cmd.Wait()函数。如果需要终止命令的执行，可以调用Cmd.Process.Kill()来杀死进程。同时，我们还可以通过设置Cmd.Process.Pid变量，来获得命令执行的进程ID。

总体来说，CommandContext函数是exec包中一个非常实用的函数，可以让我们方便地运行外部命令，并且控制命令的执行过程。



### Command

`Command`函数是Go内部包`internal/exec`中的一个函数，用于创建一个新的命令，然后返回该命令的一个结构体指针。

在Go中，执行一个外部命令通常使用`os/exec`包中的`Command`函数。但是`os/exec`包是对外开放的公共包，而`internal/exec`是Go内部专用的包，用于实现一些Go内部的功能。

`Command`函数与`os/exec`中的`Command`函数的功能类似，但是它的实现更加灵活和可定制化，并且可以与一些特定的平台或系统特性进行交互，例如Windows的环境变量、管道和所有权等。

具体来说，`Command`函数可以接受多个字符串参数作为命令和参数，用于指定要运行的命令及其参数值。例如：

```
cmd := Command("ls", "-l", "/tmp")
```

上面的代码将创建一个新的命令结构体，该结构体将运行`ls -l /tmp`命令，并返回一个指向该结构体的指针。`Command`函数的返回值是`*Cmd`类型，其中包含了该命令的执行状态、输入和输出管道等信息。可以使用该结构体的方法来执行命令、读取命令输出、等待命令执行完成等操作。

需要注意的是，`internal/exec`包是Go的内部包，未来的版本可能会对其进行更改或移除。因此，建议只在需要直接操作系统级别的细节时才使用该包中的函数。否则，建议使用`os/exec`等公共包中提供的函数，以确保代码的兼容性和可移植性。
