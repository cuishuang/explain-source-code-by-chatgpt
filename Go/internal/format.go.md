# File: format.go

format.go是Go语言标准库中internal包中的一个文件，其主要作用是提供了一些内部使用的格式化函数。

这些函数包括：

1. formatBits(b uint64) string：将一个无符号整数转换成二进制形式的字符串。例如，formatBits(42)将返回"101010"。

2. formatDuration(d time.Duration) string：将一个时间段转换成字符串形式。例如，formatDuration(2*time.Hour + 30*time.Minute)将返回"2h30m"。

3. formatFraction(num, denom int64, prec int) string：将分子和分母给定的分数转换成字符串形式，并指定保留小数点后的位数。例如，formatFraction(5, 7, 3)将返回"0.714"。

4. formatGoString(value interface{}) string：将一个Go语言值转换成字符串形式，类似于fmt包中的%#v格式。例如，formatGoString([]int{1, 2, 3})将返回"[]int{1, 2, 3}"。

5. formatNodeOffset(fset *token.FileSet, pos token.Pos) string：将一个token.Pos类型的位置转换成文件名和行号的形式。例如，假设有一个文件file.go的第80行第10个字符是一个标识符的位置，formatNodeOffset(fset, pos)将返回"file.go:80:10"。

这些函数在Go语言的其他标准库中广泛使用，但是不应该被外部程序使用。因为internal包是Go语言中的一种约定，表示这个包只能被当前模块中(importing module)的其他包引用，而不能被其他模块使用。这保证了module的封装性和隔离性。

### SetPackage

在 Go 语言中，每个文件都必须属于一个包，可以通过 package 关键字来指定一个文件所属的包。一个包通常由多个文件组成，它们必须属于同一个目录，并且它们的 package 声明也必须相同。

在 gofmt 工具中，SetPackage 是一个用于设置文件的包声明的函数。它会将传入的文件的 package 声明设置为给定的字符串，常用于将多个文件合并为一个文件时，设置合并后文件的包声明。

该函数的签名如下：

```go
func SetPackage(fset *token.FileSet, file *ast.File, name string)
```

其中，fset 是一个 token.FileSet，用于定位语法节点在源文件中的位置；file 是一个 ast.File，表示需要设置包声明的目标文件；name 是一个字符串，表示需要设置的包名。

该函数的具体实现流程如下：

1. 首先，使用 ast 包中的 NewIdent() 方法创建一个新的标识符（Identifier）节点，用于表示包名。

2. 然后，将该标识符节点封装为一个 BasicLit（基本字面值）节点，这是因为包名必须是一个字符串字面值。 

3. 接着，创建一个 pkgDecl 变量，用于表示当前文件中的 package 声明节点。 

4. 如果该文件中已经存在 package 声明节点，则将其替换为新的 package 声明节点；否则，创建一个新的 package 声明节点并添加到文件的开头位置。

5. 最后，使用 token.FileSet 对象的 Position() 方法更新新的 package 声明节点的位置信息。

总之，SetPackage 函数的作用是将指定文件的 package 声明设置为指定的包名，常用于将多个文件合并为一个文件时设置合并后文件的包声明。

### EmitPercent

EmitPercent是format.go中的一个函数，用于将字符串中的百分号（%）转义为两个百分号（%%）。

在Go语言中，百分号是格式化字符串的特殊字符，用于指定格式化输出的方式。例如，`fmt.Printf("Hello, %s!", name)`会将变量name的值代入字符串中的%s占位符。

如果字符串中本身就需要出现百分号，例如打印一个百分比，就需要将字符串中的百分号进行转义，否则会被当做格式化字符串的特殊字符解析。这时，可以使用两个百分号（%%）来表示一个百分号。

而EmitPercent函数就是实现这个百分号转义的过程。它接受一个字符串作为参数，遍历字符串中的每个字符，如果遇到了百分号，就在输出字符串中添加一个百分号。最终，输出字符串中的百分号都被转义为两个百分号。

下面是EmitPercent函数的代码：

```
func EmitPercent(fset *token.FileSet, pos token.Pos, expr string) string {
    // ...
    n := 0
    for _, c := range expr {
        if c == '%' {
            b.WriteRune(c)
            b.WriteRune(c)
        } else {
            b.WriteRune(c)
        }
        n++
    }
    // ...
    return b.String()
}
```

其中，b是一个bytes.Buffer类型的变量，用于存储输出字符串。遍历字符串中的每个字符，如果遇到了百分号，就将两个百分号写入输出字符串中；否则就直接将字符写入输出字符串中。最后，将输出字符串作为函数的返回值。



### EmitFuncs

EmitFuncs函数是go/src/internal/format/format.go中的一个函数，它的作用是向输出流中写入函数列表中的每个函数的格式化字符串。

函数列表是一个具有以下类型的结构体切片：

type Func struct {
	Doc  *ast.CommentGroup // 文档注释
	Decl *ast.FuncDecl     // 函数声明
}

EmitFuncs函数会调用emit函数来逐个输出Func结构体中的函数。emit函数在输出每个函数之前都会输出函数的注释。

EmitFuncs函数的具体步骤如下：

1. 判断函数列表是否为空，如果为空则直接返回。

2. 遍历函数列表中的每个函数，用emit函数把它输出到输出流中。

3. 如果函数列表中的最后一个函数后有多于一个空行，那么会把这些多余的空行全部去掉，只留下一个。

通过EmitFuncs函数，我们可以很方便的将一个函数列表中的所有函数输出为格式化字符串，这在实现代码打印功能时非常有用。
