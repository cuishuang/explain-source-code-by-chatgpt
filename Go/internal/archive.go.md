具体来说，archive.go主要包含以下几个部分：

1. 常量和变量定义：该部分定义了一些常用的归档格式的常量和变量，例如ZIP、GZIP、TAR等。

2. 接口定义：该部分定义了不同类型归档处理器所需实现的接口，例如Reader、Writer等。

3. 结构体定义：该部分定义了不同类型归档处理器对应的结构体，如Reader、Writer、gzipReader、gzipWriter等。

4. 函数实现：该部分实现了对不同类型归档处理器的读取、写入、解压缩等操作函数，例如NewReader、NewWriter、Read、Write、Flush等。

通过使用archive.go中所提供的接口、结构体和函数，开发者可以轻松地读取和写入各种归档格式的文件，从而实现数据的压缩和解压缩操作。同时，archive.go还提供了一些方便的辅助函数，如IsArchive、RegisterFormat等，帮助开发者识别和注册新的归档格式。

### newlineMarker

newlineMarker变量是一个字节数组，用于在Tar档案中添加新的目录或文件时，作为目录和文件的结尾标志符。

在Tar档案中，每个文件或目录都以一定的格式表示，其中每个文件或目录结束时都需要一个结尾标志符。该标志符通常为全0字节，但是在某些情况下，它可以是任何字节序列，只要在同一Tar档案中不重复即可。

newlineMarker变量用于在Tar档案中添加新目录或文件时，作为上一个文件或目录的结尾标志符。它通常为全0字节序列，但在某些情况下可能是其他字节序列。

总之，newlineMarker变量是Tar档案中用于标识不同文件或目录之间分界点的结尾标志符。它确保文件和目录之间始终有一个清晰的分界点，以便后续的解压缩和处理。



### marker

在Go语言的archive包中，marker变量的作用是标识二进制文件中的一个字节序列。这个字节序列是用来区分不同压缩格式的。在读取二进制文件时，程序会先读取marker所标识的字节序列，通过这个序列便可以确定压缩格式，然后再开始解压缩操作。

marker变量的值是一个byte类型的数组，它的定义如下：

```go
var (
    // gzip格式的标识
    gzipHeader = []byte{0x1f, 0x8b, 0x08}
    // zip格式的标识
    zipHeader  = []byte{'P', 'K', 0x03, 0x04}
    // tar格式的标识
    tarHeader  = []byte{'u', 's', 't', 'a', 'r', 0}
    // elf格式的标识
    elfHeader  = []byte{0x7f, 'E', 'L', 'F'}
    // mach-o格式的标识
    machoHeader = []byte{0xfe, 0xed, 0xfa, 0xce}
)
```

其中，gzipHeader、zipHeader、tarHeader、elfHeader、machoHeader分别表示gzip、zip、tar、elf和mach-o这几种二进制格式的标识。在archive.go文件中的Open函数中，会根据marker变量的值判断输入的文件类型，进而选择相应的解压缩方式。



### markerEnd

在 `archive.go` 文件中，`markerEnd` 这个变量是一个字节切片，用于标记压缩文件的结尾。它的作用是在不知道文件长度的情况下，确定压缩文件的结尾。

在 `archive/tar` 包中，`markerEnd` 的值为 `"\x00\x00\x00\x00\x00\x00\x00\x00\x00\x00\x00\x00\x00\x00\x00\x00"`，也就是 16 个 null 字节，表示一个空磁带块，即空文件。这个空文件标记了 tar 文件的结尾。

在 `archive/zip` 包中，`markerEnd` 的值为 `[]byte{0x50, 0x4b, 0x05, 0x06}`，表示 zip 文件的结尾标记字段。这个字段包含了 zip 文件的总大小以及所有文件和目录的偏移量，用于告诉解压程序在哪里找到压缩包的内容。

总之，`markerEnd` 是一个用于标记压缩文件结尾的固定字节数组或切片。通过识别 `markerEnd`，可以在不知道文件长度的情况下确定压缩文件的结尾，从而正确读取压缩文件的内容。

### File

File结构体是在Go语言标准库中的archive包中定义的。它的作用是表示一个存档文件（如tar、zip等），用于在对存档文件进行读取、写入、解压等操作时进行数据存储和传递。

File结构体包含了存档文件中的一个文件的相关信息，如文件名、文件大小、权限等。同时它也可以是一个目录、符号链接等特殊类型的文件。File结构体的定义如下：

```go
type File struct {
    // 存档文件中的文件名（相对路径）
    Name string 

    // 存档文件中的文件大小（单位为字节）
    Size int64 

    // 存档文件中的文件权限
    Mode FileMode 

    // 存档文件中的最后修改时间
    ModTime time.Time 

    // 存档文件中的文件内容
    // FileHeader.Size字段存储了文件大小，可以通过io.LimitReader来读取指定长度的数据
    // 如果该文件是个符号链接，则该字段存储的是符号链接目标的路径
    // 如果该文件是个目录，则该字段为空
    // 如果该文件没有内容，则该字段为空
    Reader io.Reader 

    // 存档文件中该文件的头信息
    FileHeader *FileHeader 

    // 存档文件中该文件对应的存储位置
    // 如果该文件是压缩存档中的文件，则该字段可以获取该文件在解压后的存储位置
    Offset int64 

    // 包含存档文件的大小和校验信息，用于验证存档文件是否有损坏或篡改
    Validator Validator 
}
```

File结构体是archive包的一个重要组成部分，可以让我们更加方便地读取、写入和解压存档文件中的内容。同时它也为存档文件的其他操作，如压缩、添加、删除等操作提供了良好的数据结构支持。

### isMarker

isMarker函数是用来检查给定的字节数组是否是zip文件的标志符。一个zip文件的标志符是由4个字节组成的，它的值为"PK\x03\x04"。如果一个字节数组的前4个字节的值与这个标志符相同，则可以判断它是一个zip文件。

在archive.go文件中，isMarker函数是用来检查给定的字节数组是否是一个zip文件的标志符。如果一个文件的标志符不是"PK\x03\x04"，则该文件不是一个有效的zip文件，isMarker函数将返回false。

isMarker函数的定义如下：

```
func isMarker(buf []byte) bool {
	return len(buf) >= 4 && buf[0] == 'P' && buf[1] == 'K' && buf[2] == 3 && buf[3] == 4
}
```

这个函数首先检查字节数组的长度是否大于等于4，然后检查前四个字节是否等于"PK\x03\x04"。如果是，就返回true，否则返回false。



### fixNL

fixNL函数在Go语言内部的archive模块中，用于修复文本文件中的换行符。

在不同的操作系统中，文本文件的换行符可能不同，比如在Windows系统中使用"\r\n"表示换行，在Unix系统中使用"\n"表示换行。而在文件被压缩后，这些换行符可能会被改变，造成不同系统之间的文本文件显示出错。

fixNL函数的作用就是将所有的换行符都转换为Unix系统中的"\n"，确保文件在任何系统中都能正确显示。具体实现方式是通过遍历文本文件的每一行，将其中的"\r\n"或"\r"替换为"\n"。

总之，fixNL函数是一个很重要的函数，它确保了文件在被压缩后仍能够被正确地显示，并且减少了不必要的跨系统兼容性问题。
