# File: net_wasip1.go

net_wasip1.go 文件实现了一个 Windows 下的函数 `netWasIP1`，此函数主要在运行时判断当前系统是否已经安装了 IPv6 功能，如果安装了 IPv6，那么返回 true，否则返回 false。

这个函数是在 Go 1.8 中新增的，其主要作用是提高 Windows 平台下网络相关代码的兼容性和效率。因为 Windows 平台下在启用 IPv6 功能时会增加很多运行时判断和转换的代码，所以预先知道该系统是否启用了 IPv6 功能，就可以减少这些代码的运行，提升程序执行效率。

在 Go 1.15 中，该函数的实现已经被移动到了 sys/windows 包中，而不再在 internal 中了，但其使用方法和功能基本不变，仍然是用于判断当前系统是否启用了 IPv6 功能。

### RecvfromInet4

RecvfromInet4是一个用于在IPv4网络上接收数据包的函数。它负责从一个UDP套接字中读取数据，并解析出数据的来源IP地址和端口号。

该函数接受三个参数：

- fd：一个已经绑定到某个端口号的UDP套接字描述符。
- p：一个包缓冲区，函数将从UDP套接字读取数据包并将其写入该缓冲区。
- oob：一个溢出缓冲区，用于从UDP套接字接收控制消息。在IPv4网络上，这通常是为空的。

函数返回四个值：

- n：接收到的数据的字节数。
- from：一个IP地址和端口号，表示数据包的来源。
- ttl：该数据包的IP TTL（生存时间）值。
- err：一个错误，表示函数执行期间是否出现任何错误。

该函数的主要作用是从UDP套接字接收数据并将其解析为IPv4数据包。它通常用于实现UDP协议的服务器或客户端。
