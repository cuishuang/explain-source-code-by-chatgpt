# File: xxhash.go

go/src/internal/xxhash.go 是 Go 语言中实现了 xxHash 哈希算法的源代码文件。xxHash 是由 Yann Collet 所开发的非加密型哈希算法，已经被广泛地应用于数据校验、大数据处理等领域，其特点是高速、高效、碰撞率低。

xxHash 哈希算法是一种基于哈希表实现的数据结构，其基本原理是：将数据（字节数组）经过一系列 shift、异或、乘法、加法等变换后得到一个哈希值，然后将该哈希值存入哈希表中相应的桶中。在查询过程中，同样对被查询的数据进行变换得到哈希值，并在哈希表中查找相应的桶，从而得到被查询数据的位置。

Go 语言在内部实现 xxHash 算法，从而提供更高效的哈希计算。该文件提供了 xxHash 算法的实现，包括基本的哈希计算、更新哈希值、重置哈希值、返回最终哈希值等功能。在 Go 语言的相关程序中，可以通过调用 xxhash 包来使用该算法，从而加速相关计算的过程。

## Functions:

### reset

reset函数的作用是将当前的xxhash状态重置为初始状态，以便重新开始使用xxhash进行哈希计算。具体来说，reset函数会将hash值、总字节数、缓冲区中剩余的字节数清零。这样就可以在不用新建一个xxhash对象的情况下对同一组数据重新进行哈希计算。

reset函数主要在两种情况下使用：

1. 在初始化xxhash对象时，需要将对象的状态重置为初始状态。
2. 在处理大文件或大数据流时，xxhash可能会将数据分成多个块进行处理。当处理完一个块后，需要调用reset函数将状态重置为初始状态，然后处理下一个块的数据。

重置状态的好处是可以避免前一个哈希计算的状态影响下一个哈希计算的结果。因此，在需要对同一组数据进行多次哈希计算时，reset函数是非常有用的。



### update

update这个func是xxhash算法中的一个重要步骤之一，用于在进行哈希计算时更新xxhash状态。

在xxhash算法中，将待哈希的数据分成若干个块（chunk），每个块的大小为4字节，对于最后一个块，如果不足4字节，则用0来填充。update函数的作用就是对一个块的数据进行处理，更新xxhash状态。

函数定义如下：

```go
func (d *digest) update(p []byte) {
    var (
        i   int
        ln  = len(p)
        end = ln
    )
    d.nbytes += uint64(ln)
    if d.memsize+ln < xChunkSize {
        // not enough data for a full chunk, so just add to buffer
        copy(d.mem[d.memsize:], p)
        d.memsize += ln
        return
    }
    if d.memsize != 0 {
        // fill partial chunk
        copy(d.mem[d.memsize:], p)
        d.processChunk(d.mem[:])
        i += xChunkSize - d.memsize
        end -= i
        d.memsize = 0
    }
    for ; i+4 <= end; i += 4 {
        d.processChunk(p[i:])
    }
    if i < end {
        copy(d.mem[d.memsize:], p[i:])
        d.memsize = end - i
    }
}
```

可以看到，函数做了以下几件事情：

1. 计算待更新的数据长度，将其加入到d.nbytes中，表示已处理的字节数。
2. 如果待更新数据的长度还不够一个块，将这些数据添加到d.mem中，并更新d.memsize。
3. 如果d.mem中已经积累了足够4字节的数据，就处理这个块，更新xxhash状态，并将i指针前移xChunkSize-d.memsize。
4. 处理剩余的数据，如果不够4字节，就放到d.mem中等待下一次处理。

可以看到，update函数的作用是将每一个块的数据进行处理，并更新xxhash的状态，这个函数的实现很巧妙，利用了d.mem存储暂时还不够构成一个完整块的数据，以及变量i表示当前处理到了哪个位置的数据。最终，update函数会在d.digest()中被调用，在处理完所有数据块后生成最终的hash值。



### digest

digest()是xxhash.go文件中的一个函数，它的作用是计算数据流的XXH64散列值。

具体的作用方式如下：

1. 初始化一个xxHash64实例

2. 将数据流逐块输入到xxHash64实例中

3. 调用XXH64Digest()方法计算散列值

简单来说，digest()函数就是通过将输入的数据流逐块输入到xxHash64实例中，计算出整个数据流的XXH64散列值的。在实际应用中，散列值用于判断数据是否完整，进行数据校验，或者用于数据签名等方面。

需要注意的是，digest()函数是由内部调用XXH64Digest()方法来计算散列值的。这个方法是xxHash64实例自带的，不需要手动调用。

总之，`round`函数的作用是对输入数据进行哈希运算，是XXHash算法实现的核心部分之一。



### mergeRound

mergeRound函数是xxhash算法中的一个核心组成部分，它用于将两个32位整数进行混合计算。

具体来说，mergeRound函数接收三个输入参数：v1、v2和r1。其中，v1和v2是两个32位整数，r1是一个uint巨集，表示该轮计算的偏移量。该函数通过对v1和v2进行按位异或（XOR）运算，并将运算结果与r1相加，再乘以二进制常数0x9e3779b1ul，最后对运算结果进行旋转、加法、乘法等操作，从而对两个整数进行混合计算。

mergeRound函数在xxhash算法中被广泛使用，它可以用于对任意长度的数据进行快速的哈希计算，也可以用于对多个哈希值进行混合计算，从而得到一个全局的哈希值。由于mergeRound函数的高效性和可靠性，它在各种计算机系统和应用领域中被广泛应用。
