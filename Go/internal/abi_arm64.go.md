# File: abi_arm64.go

abi_arm64.go 是 Go 语言源码中的一个文件，位于 go/src/internal 目录下，其作用是定义了 ARM64 平台上的函数调用规则和参数传递方式。

在 ARM64 架构下，函数参数的传递和返回值的处理方式是通过 CPU 寄存器来完成的。但不同的寄存器有不同的使用约束和调用规则。abi_arm64.go 中定义了在 Go 语言中的函数调用规则和参数传递方式，这包括了寄存器使用顺序，以及不同类型的参数在不同寄存器中的传递方式。

除了定义函数调用规则和参数传递方式之外，abi_arm64.go 还提供了一些辅助函数和类型定义，用于帮助在 Go 语言中编写 ARM64 平台上的汇编代码。

总的来说，abi_arm64.go 的作用是保证在 Go 语言中 ARM64 平台上的函数调用方式与底层的 CPU 设计实现相兼容。这是保证程序稳定、正确性和性能的关键。
