# File: table.go

table.go文件定义了从golang源代码生成的语法分析表。table.go中的表格数据在编译时使用，帮助解析器分析golang代码。 

具体来说，table.go文件定义了两个重要的结构体: actionTable和gotoTable。它们是LR(1)分析表的核心数据结构之一。它们存储了语法解析器在解析过程中须要使用的动作（如移进和规约）和状态转移动作的规则。

actionTable结构体定义了parser在不同的状态下应该采取的动作，例如移位、规约或者接受。当解析器处于一个状态时，actionTable会告诉它下一步该采取何种动作。

gotoTable则定义了文法符号之间的转移关系。它记录了解析器当前状态下在遇到下一个符号时应该转移到的状态。

总之，table.go的作用是为golang编译器提供了支持，帮助解析器正确地解析语法结构。

### Var:

### All

在go/src/internal中的table.go文件中，All变量是一个 type Table 结构体指针数组的变量。它的作用是存储了所有的 Go 布局表，这些布局表用于识别 Go 二进制文件中的各个部分。

在这个文件中，type Table 结构体定义了布局表的结构，其中包括了如下字段：

- magic uint32 ：文件的魔数
- offset uint32 ：在文件中的偏移
- name string ：模块名称
- pctab uint32 ：pcdata表的偏移量
- funcnameoff uint32 ：函数名称表的偏移量

通过这些字段可以准确地识别出二进制文件中的各部分，包括函数、变量、常量等等，这对于调试和优化 Go 应用程序非常有用。

在All变量中，每个元素都是一个 type Table 结构体的指针，表示一个布局表。当需要识别二进制文件中的某个部分时，可以遍历 All 数组，寻找和匹配相应的布局表。如果匹配成功，则说明找到了对应的部分，可以进行下一步操作。

### Structs:

### Info

在Go语言中，每个包都会生成一个对应的符号表，用于记录包中的函数、变量、常量等信息。在internal包中，也有自己的符号表。table.go文件中的Info结构体即为该符号表中每个符号对应的信息。

Info结构体记录了一个符号的名称、标识符（identifier）、类型、值、地址等信息。其中，名称和标识符是必须的，类型、值和地址则根据符号类型的不同而有所不同。比如函数对应的符号类型是Func，其类型字段记录的就是函数的返回类型；变量对应的符号类型是Var，其值字段记录的就是变量的初始值；常量对应的符号类型是Const，其值字段记录的就是常量的值。

在Go语言的编译过程中，编译器会遍历源代码文件，生成每个包对应的符号表。当其他包需要引用某个包中的符号时，会通过该符号的名称来查找对应的Info结构体，以获取符号的相关信息。因此，Info结构体对于Go程序的正确编译和运行是非常重要的。

总结来说，Info结构体在internal包中扮演着记录符号表信息的重要角色，它记录了每个符号的名称、标识符、类型、值、地址等信息，是Go程序正确编译和运行的基础。



## Functions:

### Lookup

Lookup函数是Go语言内部的一个函数，它用于查找给定的字符串在内部表格中的索引。这个函数的作用非常重要，因为它在Go语言的编译器、运行时和其他一些核心库中被广泛使用。

具体来说，Lookup函数被用于读取内置函数的索引、确定符号的类型和进行语法分析。它需要传入一个字符串，然后返回该字符串在内置表格中的索引。如果该字符串不存在于表格中，则返回一个负数。

内置表格是一个包含了各种内置函数、常量和类型的集合。这些元素是在Go语言的编译器和运行时中定义的，它们在需要时通过Lookup函数来查找。

总之，Lookup函数是Go语言内部非常重要的一个函数，它在Go的编译器、运行时和其他核心库中被广泛使用，可以用于查找内置表格中的元素索引。
