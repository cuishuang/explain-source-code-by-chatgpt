# File: maphash_purego.go

maphash_purego.go是Go语言中hash包的一个子包，主要实现了基于纯Go的方式进行哈希计算的算法。该文件的作用是提供一种基于纯Go的哈希计算方式，为实现哈希算法的其他程序提供支持。

具体来说，该文件实现了MapHash结构体及其相关方法，MapHash结构体是一种用于计算哈希值的结构体，可以使用其hash方法计算一个任意字节序列的哈希值。该哈希值可以用于实现哈希表、数据结构、加密算法等多个领域。MapHash结构体的实现基于Kirsch-Mitzenmacher-2006哈希算法，该算法是一种非常快速和高效的哈希算法。

除了MapHash结构体之外，该文件还定义了一组MapHash相关的常量，用于控制哈希算法的参数和表达哈希值的格式。这些常量包括默认的哈希种子，用于计算哈希值时的补偿因子，用于指定哈希值输出的大小等。

在整个hash包中，maphash_purego.go对于Go语言底层实现高性能哈希算法具有重要的作用。同时，maphash_purego.go还可以被其他使用哈希算法的Go语言程序直接引用，提供纯Go实现的哈希计算能力，从而扩展了Go语言在数据处理方面的能力。

该函数的具体实现方法是使用了一种称为“逆向散列”的算法，主要思想是将一个整数的位反转，然后进行哈希运算。这种方法具有很好的随机性和强大的抗碰撞能力，因此在哈希算法中得到了广泛应用。

1. 将输入的无符号整数x的每一位存储在一个bool类型的数组中，即将x表示为二进制数。
2. 将这个bool数组中的元素按照位序颠倒，即第1位变为第64位，第2位变为第63位，以此类推，得到一个新的bool数组y。
3. 将y中的每一位转化为0或1的uint64类型数字，并以此构建一个新的无符号整数z。
4. 对z进行哈希运算，得到一个64位的哈希值作为函数的返回结果。

总的来说，rthash函数是一种高效且安全的哈希算法，常被用于哈希表、密码学等领域中。

### leUint32

leUint32这个func是将一个uint32类型的整数转换成一个小端序（little-endian）byte数组。在计算hash值的过程中，需要把输入的key转换成byte数组，然后再对这个byte数组进行计算。这个计算过程需要使用小端序，因为Go语言中的哈希算法采用了little-endian字节序。因此，需要将uint32类型的整数按照little-endian字节序转换成byte数组。

具体实现方式是将该uinit32类型的整数拆分成4个byte，然后按照little-endian字节序排列，最后得到一个长度为4的byte数组。这个byte数组可以直接用于计算hash值。

下面是leUint32的函数实现代码：

```
func leUint32(a uint32) [4]byte {
    return [4]byte{
        byte(a),
        byte(a >> 8),
        byte(a >> 16),
        byte(a >> 24),
    }
}
```

该函数使用了一个长度为4的数组来保存转换后的结果。byte(a)将a的最低8位转换成一个byte类型的值，byte(a >> 8)将a的第9到16位转换成byte类型的值，以此类推。最后，将这四个byte类型的值放入数组中，就得到了一个小端序的byte数组。
