# File: crc64.go

crc64.go文件实现了两个函数，分别是crc64和makeTable，用于计算64位循环冗余校验（CRC）码。

CRC码是一种数据校验方式，其计算方式是按照预定义的多项式对数据进行计算，最终产生一个校验值，将校验值附加在数据末尾发送出去，接收方也按照同样的计算方式计算校验值，将其与接收到的校验值比对，如果相等，则说明数据没有损坏，否则说明数据有损坏。因此，CRC码可以用于检测数据的完整性和可靠性。

crc64函数通过使用多项式0xC96C5795D7870F42来计算数据的CRC64码。makeTable函数用于创建这个多项式的查找表，以加速CRC64码的计算。

crc64.go文件的实现可以用于需要进行CRC校验的应用程序和协议中，如文件传输、网络通信等。

### Table

CRC 算法是一种通过计算数据位运算并产生固定宽度比特校验和的方法，这种校验和可以用于检测传输或存储中的数据是否被损坏或篡改。在 CRC 算法中，参数表格（Table）是用于为每个数据位计算出对应的校验和的。

在 hash/crc64 包中，Table 结构体定义了一个预定义的 CRC 码表，其中记录了 CRC 算法计算中需要用到的多项式和初始值等参数。这些参数被组织为一个无符号整数切片，它是在生成 CRC 码时用于快速计算 CRC 校验和的。

例如，crc64 表格的定义如下：

```go
var isoTable = &Table{
    isoPoly,
    isoTable256[:],
    uint64(1) << 63,
}
```

其中，`isoTable` 是一个指向 Table 结构体的指针，用于描述 ISO 标准的 CRC64 算法中的参数表格；`isoPoly` 是多项式参数；`isoTable256[:]` 是256个无符号整数的表格，用于 ISO CRC64 校验和计算中转换输入数据；`uint64(1) << 63` 是初始值参数。

使用 Table 结构体，可以快速生成 CRC 校验和，并进行校验码验证。比如，可以通过 hash/crc64 包中的 Checksum 函数计算一个数据的 CRC64 校验码：

```go
data := []byte("hello, world")

checksum := crc64.Checksum(data, table)
fmt.Println(checksum)
```

这里使用了 `MakeTable` 函数获取 ECMA 标准的 CRC64 码表，然后把数据 `data` 和码表 `table` 传入 Checksum 函数获取对应的校验码。如果要验证数据的完整性，需要先计算出校验码，然后将数据和校验和传输到接收方，接收方同样需要使用相同的参数表格和数据计算出接收到的数据的校验和，用计算出的校验和和接收到的校验和进行比较，相同说明接收到的数据是正确的，否则说明数据可能被篡改或损坏。



### digest

digest 结构体是用于计算 CRC-64 校验值的内部状态结构体，它由 2 个 uint64 类型的字段组成。

在进行 CRC-64 校验计算时，会将输入数据拆分为固定大小的块，每个块都会更新 digest 结构体的状态。最终，根据已处理的数据块以及 digest 结构体的状态，可以计算出 CRC-64 校验值。

digest 结构体的两个字段分别表示当前状态的高 64 位和低 64 位。通过记录已处理数据块的数量以及 digest 的当前状态，可以在处理完所有数据块后，准确计算出 CRC-64 校验值。

在 CRC-64 校验计算过程中，digest 结构体可以认为是一个缓冲区，它会存储已经处理的数据块的状态，在计算 CRC-64 校验值时不需要重新计算每个块的校验值，可以直接使用 digest 结构体的值进行计算，从而减少计算量，提高效率。

### makeTable

makeTable函数是用于生成一个长度为256的uint64数组，用于计算CRC64校验值。该数组的每个元素都是一个预先计算好的值，称为CRC多项式的Lookup table（查找表），具体作用如下：

1.提高计算效率：通过预先计算CRC多项式和数据流的每个8位字节的异或值，生成了一个包含256个uint64型元素的表。在计算CRC校验码时，只需要将每个字节值作为下标去查找表中的预计算值，然后进行异或和移位操作。这种查表法比直接使用多项式计算方法更高效，可以大幅减少CPU的计算负担，提高CRC校验速度。

2.保证校验值唯一性：生成CRC多项式的Lookup table只需要运行一次makeTable函数，生成的表在整个程序周期内都可以重复使用。这样可以保证算出的CRC校验值唯一性，不易发生误判。

3.支持标准化：生成CRC多项式的Lookup table具有标准化的特性，即不同平台或编译器生成的表结果应当相同。因此，一份标准的CRC64计算程序可以在不同的硬件平台或操作系统下运行，并保证CRC校验结果一致。

总之，makeTable函数的作用就是生成用于计算CRC64校验值的Lookup table，提高计算效率，保证校验值唯一性，支持程序标准化。

### Checksum

`Checksum` 是 `crc64` 包中的一个函数，可以计算给定数据的 CRC-64 校验和。

CRC（循环冗余校验）是一种检验数据传输中出现错误的方法。CRC-64 是一种基于 64 位的 CRC 校验，可以用于确保数据的完整性。

`Checksum` 函数接受两个参数：一个 `polynomial`（多项式）和一个 `data` 字节切片。`polynomial` 指定用于计算校验和的多项式，而 `data` 切片则是要计算 CRC-64 校验和的数据。

该函数返回一个 uint64 类型的哈希值，表示给定数据的 CRC-64 校验和。

以下示例演示了如何使用 `Checksum` 函数计算数据的 CRC-64 校验和：

```go
package main

import (
    "fmt"
    "hash/crc64"
)

func main() {
    data := []byte("Hello, world!")
    polynomial := crc64.MakeTable(crc64.ECMA)
    checksum := crc64.Checksum(data, polynomial)
    fmt.Printf("CRC-64 checksum: %d\n", checksum)
}
```

输出：

```
CRC-64 checksum: 10661671454580169872
```

可以看到，输出的哈希值是一个 uint64 类型的整数，可以用于验证数据的完整性。
