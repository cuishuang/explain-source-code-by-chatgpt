# File: fnv.go

fnv.go是Go语言中标准库hash包中实现FNV hash算法的代码文件。FNV (Fowler-Noll-Vo) hash算法是一种非加密的hash算法，能够在常数时间内对输入数据进行hash运算，其性能表现优越，比一些其他hash算法速度更快。FNV算法的优点是可以快速地计算大量的hash值，而且非常简单，计算速度很快。

fnv.go文件中定义了两个hash函数：New32和New64。New32返回一个新的32位FNV-1哈希.Hash，并初始化为零值。New64返回一个新的64位FNV-1哈希.Hash，并初始化为零值。这两个函数将输入数据转换为整数，并根据FNV算法生成一个数字hash值。

FNV算法的实现基于两个参数：FNV基础偏移量和FNV质数。它们被用于计算32位和64位哈希值。这些参数已经被证明在hash算法中表现很好，并且已经得到广泛使用。因此，FNV算法在实际应用中非常流行。

总之，fnv.go文件的作用是提供快速、高效的FNV hash算法实现，它可以在常数时间内对任意大小的数据进行hash计算。这使得它可以在各种场景下使用，例如数据校验、存储哈希表等。

### sum32

### New32a

New32a是一个函数，它的作用是返回一个新的32位无符号整数哈希器，该哈希器使用FNV-1a哈希算法。

具体来说，FNV-1a是一种基于乘法的哈希算法，它是由Glenn Fowler、Landon Curt Noll和Phong Vo在2002年开发的。FNV-1a算法根据给定的数据生成一个哈希值，这个哈希值可以用来检索更大的数据结构（例如哈希表）中存储的数据。FNV-1a算法在计算哈希值时，对于每个字节都使用一个常数（FNV-1a使用的是32位无符号常数）进行乘法计算，并将结果与当前的哈希值异或。最终，FNV-1a算法返回异或后的哈希值，以此作为数据的唯一标识。

在Go语言中，New32a函数是hash/fnv包中的一个函数，它返回一个新的32位无符号整数哈希器，可以使用它来计算数据的哈希值。它使用FNV-1a哈希算法，可以对数据进行逐字节的哈希处理，以生成唯一的哈希值。使用New32a函数，可以方便地处理数据的哈希值，并用于存储或检索需要长期保存的数据。



### New64

New64是一个函数，它返回一个64位的哈希器，它实现了64位的FNV-1哈希算法，它可以用于对数据进行哈希操作。哈希操作可以将任意长度的数据映射为一个固定长度的哈希值，并且保证同样的数据会得到同样的哈希值，不同的数据则会得到不同的哈希值。这样的特性使得哈希函数在数据比较和查找等操作中非常有用。

在New64函数中，它返回的哈希器是一个FNV-1a哈希器，它使用Fowler-Noll-Vo(FNV)哈希算法。这个算法非常简单，它对数据进行了连续的一系列位运算和异或运算，并将结果作为哈希值返回。FNV算法的优点在于它的速度非常快，并且能够保证相对较低的哈希冲突率。

使用New64函数，可以很方便地对数据进行哈希操作，例如：

```go
import (
    "hash/fnv"
)

func main() {
    data := []byte("hello world")
    hasher := fnv.New64()
    hasher.Write(data)
    hash := hasher.Sum64()
    fmt.Printf("Hash value: %d", hash)
}
```

这个例子中，我们先创建了一个数据字节切片，然后创建了一个FNV-1a哈希器，将数据写入哈希器中，计算哈希值，并输出到屏幕上。

### Sum32

Sum32是一个函数，它的作用是基于Fnv-1a算法计算提供的数据的32位哈希值。

Fnv-1a算法（Fowler–Noll–Vo hash function）是一种哈希算法，它采用乘数方式计算哈希值，具有很好的性能和随机性。这个算法的基本思想是将初始哈希值设为一个偏移值，然后将字节序列（即提供的数据）视为整数，针对每个字节按照一定的规则更新哈希值，最后得到的哈希值即为所求。

在Sum32函数中，首先初始化哈希值为1。然后，针对提供的数据进行哈希计算。具体地，对于每个字节b，哈希值h的更新规则如下：

h = (h ^ uint32(b)) * fnvPrime32

其中，^表示按位异或操作，fnvPrime32是一个32位常数（16777619）。更新完哈希值后，返回最终的哈希值即可。

Sum32函数在Go语言标准库中被广泛使用，例如在map、set等数据结构中作为哈希函数。因为哈希函数的好坏直接影响哈希表的性能，所以对于一些需要频繁操作大量数据的场景，选择一个高效的哈希函数非常重要。



### Sum64

Sum64函数实现了FNV-1a-64哈希算法，它会对输入的字节片进行哈希，并返回一个64位的哈希值。这个哈希值具有以下特性：

- 可以接受任意长度的输入。
- 输入相同，输出相同。
- 输入不同，输出也不同。
- 对于任何输入，输出的哈希值都是非负整数。

FNV-1a-64哈希算法的步骤如下：

1. 初始化哈希值为一个固定值，这里设为14695981039346656037（这是FNV-1a算法的初始值）。

2. 对于输入的每一个字节，更新哈希值。具体地，将哈希值与字节的值相乘，并取模（取模数是2^64），然后再将结果与一个固定的常数（1099511628211）相加。

3. 最后返回哈希值。

该函数可以用于快速计算字符串、字节片等数据类型的哈希值，并通过其哈希值进行差异比较，如判定两个字符串是否相等等。在Go语言中，常用的哈希表结构和布隆过滤器等数据结构也都是基于哈希算法实现的，因此Sum64函数对于Go语言中的数据结构实现也具有重要的帮助作用。



### Write

Write函数是FNV哈希算法中的一个核心函数，主要作用是按照算法规则将输入数据的字节流进行哈希计算。具体来说，该函数将输入数据分成若干个大小相等的块（通常是64位），然后对每一个块进行如下操作：

1. 将哈希值初始化为一个固定的常数（根据算法规则和哈希值位数而定）。
2. 将块中的每一个字节依次与哈希值相乘，并将结果与哈希值进行异或操作。
3. 将哈希值作为新的起点，继续下一个块的处理，直到所有块处理完成。
4. 返回最终的哈希值。

除了上述步骤外，Write函数还会执行一些错误检查和数据流读取的操作。例如，如果输入数据的长度不是块大小的整数倍会抛出一个错误；如果读取数据时出现EOF，函数也会自动计算剩余字节的哈希值并返回。

总的来说，Write函数是FNV哈希算法中非常重要的一个组成部分，它负责将输入数据转换为哈希值，并将哈希值与后续处理结果关联起来，在实际使用中被广泛应用于数据校验、数据签名等场景。

### BlockSize

在go/src/hash/fnv.go文件中，BlockSize是一个函数，用于返回FNV哈希函数的内部块大小。该函数为一个无参函数，并返回一个无符号整数类型的值。

总之，BlockSize函数是实现FNV哈希函数的一个关键组件，它确保哈希函数在不同的计算机上都能够正确计算哈希值，并按照预期进行哈希操作。

在这个例子中，我们使用了fnv.New32()函数创建一个32位FNV哈希器，然后使用Write方法向哈希器中写入一个字符串。在内部，Write方法会将字符串转换为字节数组，并使用appendUint32函数将其追加到哈希值的末尾。最后，我们使用Sum32方法计算哈希值并打印它。

总之，`appendUint32`函数是一个用于将无符号32位整数转换为字节数组并将其追加到另一个字节数组中的便捷函数，它在哈希函数中经常被使用。



### appendUint64

在Go语言中，hash/fnv包实现了非加密的Fowler-Noll-Vo（FNV）哈希函数。在hash/fnv/fnv.go文件中，appendUint64()函数起到将一个uint64类型的整数添加到一个切片中的作用。

该函数的定义如下：

```go
func appendUint64(buf []byte, x uint64) []byte {
    // Fast path for small integers that fit in a 32-bit unsigned integer.
    if x <= 0xffffffff {
        return appendUint32(buf, uint32(x))
    }
    return strconv.AppendUint(buf, x, 10)
}
```

函数的实现非常简单：如果数字可以用32位UInteger存储，则使用appendUint32()函数将数字添加到切片中。否则，使用strconv包中的AppendUint()函数以十进制格式将数字添加到切片中。

这个函数在FNV哈希算法中用于将哈希值的结果转换为字节切片，以便可以按字节比较。当需要将哈希结果转换为可打印格式（如十六进制编码）时，也可以使用此函数。



### readUint64

readUint64函数的作用是读取一个8字节（64位）的无符号整数，并根据系统的大小端编码进行相应的字节序转换。该函数通常用于读取字节流中的哈希值，以便将其转换为Go中的uint64类型。

为了确保跨平台的兼容性，Go语言使用了固定的大小端编码规则，即大端字节序（Big Endian）。因此，在读取哈希值之前，需要检查系统的大小端编码，并相应地转换字节序，以确保正确的哈希值。

readUint64函数的实现比较简单，它首先通过调用binary.Read从输入流中读取8个字节，并将结果转换为uint64类型。然后，根据系统的大小端编码，对字节序进行转换。

总的来说，readUint64函数用于读取哈希值，并对字节序进行相应的转换，以确保正确性和跨平台兼容性。
