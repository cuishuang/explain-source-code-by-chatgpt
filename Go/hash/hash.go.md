# File: hash.go

hash.go这个文件是Go语言中哈希算法的实现文件，包含了各种哈希函数的实现，主要用于数据的唯一性验证、数据加密、哈希表等数据结构的实现等场景。

该文件中定义了一个Hash接口，该接口包含Sum方法和Write方法。Write方法用于向哈希函数中添加数据，Sum方法用于获取计算后的哈希值。

该文件实现的哈希函数包括：md5、sha1、sha256、sha512等。使用方法为：先创建一个hash.Hash类型对象，然后通过Write方法将数据输入，最后调用Sum方法输出哈希值。

除了哈希函数之外，该文件还实现了FNV哈希算法和CRC32哈希算法等。FNV哈希算法用于生成校验和或哈希表索引，CRC32哈希算法则常用于数据的完整性校验。

总之，hash.go这个文件主要用于提供哈希算法实现，为Go语言中各种数据结构和安全场景提供支持。
