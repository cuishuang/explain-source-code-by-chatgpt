# File: maphash.go

maphash.go文件的作用是实现哈希算法，它实现了一个可变长度哈希函数，称为MapHash。MapHash的输入可以是任意长度的字节数组，并且输出是一个uint64的哈希值。

MapHash是一种基于MurmurHash 3算法的哈希函数。不同于一些传统的哈希函数，MapHash执行快速的哈希计算，并且生成的哈希值在概率上是冲突极少的。这意味着MapHash可以高效地处理大规模的哈希表和散列表。

MapHash适用于对散列表中数据的分布进行概率分析，生成哈希表索引的功能。与Cryptographic Hash Function（加密哈希函数）不同，MapHash不需要保证公开可见的哈希值的安全性。

在Go语言标准库中，Map结构体、Slice结构体和Strings包中都使用了MapHash算法来实现哈希值的计算。除了这些基础的数据结构外，其他也可以使用MapHash进行哈希计算。因此，maphash.go文件的作用是提供一种快速、灵活和可靠的哈希函数，以满足大多数哈希需求。

### Structs:

### Seed

在Go语言的hash包中，Seed是一个结构体类型，它主要的作用是产生哈希函数的种子（seed）值。种子值是哈希函数用于打乱数据的初始值，根据相同的种子值计算出的哈希值在一定程度上具有随机性，因此可以提高哈希函数的安全性和散列性。

Seed结构体内部包含了一个uint64类型的值，该值可以被用作哈希函数的初始种子值。Seed结构体提供了两个方法：String和Sum64，用于从字符串或字节数组中生成种子值。

Seed结构体的使用可以帮助开发人员在对数据进行哈希计算时避免出现哈希冲突或者数据倾斜等问题，提高程序的性能和稳定性。同时，Seed结构体也提供了一种方便的途径，可以根据相同的种子值计算出相同或者相似的哈希值，这对于一些需要数据不变性的场景（如网络传输、数据存储等）非常有用。



### Hash

Hash结构体是在Go语言中实现了非加密hash函数的结构体，用于计算非加密数据的hash值。该结构体中主要包括以下成员：

1. seed：用于为hash函数输入一个种子，生成不同的hash值。

2. value：表示当前已经计算的hash值。

3. buf：表示缓存区，用于存放待hash的数据。

4. typed：表示当前待hash的数据类型，根据这个类型会对数据进行不同的处理，并计算出对应的hash值。

Hash结构体主要包括以下方法：

1. Write方法：用于将待hash的数据写入缓存区。

2. Sum方法：用于计算当前hash值并返回。

3. Reset方法：用于清空缓存区、种子和当前hash值。

Hash结构体主要用于对非加密数据进行hash，例如计算字符串、字节数组等数据的hash值。可以用于检测数据完整性、比较数据是否相同等场景。值得注意的是，由于Hash函数是非加密的，因此不能用于安全敏感的场景，例如密码验证等。

### Bytes

在 Go 语言中，`maphash` 包提供了基于哈希的散列表实现。这个包实现了 `Map` 类型，用于存储和访问键-值对。该包中的 `Bytes` 函数用于将任意字节片（`[]byte`）转换为哈希值。

具体来说，`Bytes` 函数使用 `MapHash` 算法，根据输入的字节片生成哈希值。该算法使用 MurmurHash3 算法进行加权，然后根据哈希值进行折叠。折叠过程将哈希值分成 64 位块，然后将这些块相加并取模，以获得 64 位的哈希值。

因此，`Bytes` 函数的作用是将字节片转换为可用于散列表索引的哈希值。这个哈希值可以用来定位键值对在散列表中的位置，从而加速键值对的查找和存储。

### initSeed

initSeed函数是hash包中的一个函数，它用于初始化hash算法中的随机种子。

具体来说，initSeed函数定义了一个包级变量defaultSeed，它是一个随机数，用于初始化hash算法中的随机种子。这个随机数的值是从真正的随机源中获得的。

默认情况下，这个随机数是每次运行程序都不同的，这为hash算法提供了更好的保密性和安全性，保护了hash值的生成过程不受外界攻击的影响。

initSeed函数还提供了一种方式，以多线程安全的方式改变这个默认的随机种子。这个功能在hash算法中十分重要，因为如果不改变随机种子，所有的hash值都将是同一个值，这将导致hash表中的各项指标无法正常工作。

因此，initSeed函数的作用是确保hash算法中使用的随机种子是随机的、安全的，并且可以在多线程环境下安全地修改。

### Write

在go/src/hash中的maphash.go文件中，Write函数是MapHash类型的方法，在将数据哈希到给定散列中使用。在MapHash结构中，哈希状态由4个64位无符号整数表示，并且每次调用Write函数时，将更新这些状态。Write函数的签名如下：

```go
func (h *MapHash) Write(p []byte)
```

Write函数接收一个字节数组切片p作为参数，然后将p中的数据哈希到MapHash的状态中。该函数不返回任何值。由于Write函数符合io.Writer接口，因此也可以将其他实现io.Writer接口的对象传递给它以进行哈希。例如，可以使用以下代码计算字符串"s"的哈希值：

```go
import (
    "fmt"
    "hash"
    "hash/maphash"
)

func main() {
    s := "hello world"
    var h maphash.MapHash
    h.WriteString(s)
    fmt.Println(h.Sum64())
}
```

在上面的代码中，我们首先创建一个MapHash对象" h"，然后使用其WriteString函数将字符串"s"哈希到该对象的状态中。最后，我们使用h.Sum64函数获取哈希的64位无符号整数表示形式。在本例中，最终得到的哈希值为12211635561886382263。

### Reset

Reset函数是一个MapHash类型的方法，主要用于将该对象的内部状态重置为初始状态，以准备计算下一组数据的哈希值。

具体而言，Reset函数将会执行以下操作：

1. 将该对象的内部状态hash以及buff重置为0，表示当前还没有计算任何数据的哈希值。
2. 将该对象的内部状态为seed（哈希种子）的缓冲区seed（如果存在）重置为0，以便下一次计算哈希的时候重新填充。

这个方法通常在需要多次计算不同数据的哈希值的时候使用。通过在计算完一个数据的哈希值之后调用Reset方法，可以确保该对象不会受到之前哈希值的影响，从而保证下一次计算一个新的数据的哈希值时，所得到的哈希值与上一次计算的哈希值相互独立，不会相互干扰。

此外，在该对象被使用完之后，调用Reset方法对该对象的内存进行清理，避免了内存泄漏的风险，从而提高了代码的健壮性。



### flush

在 Go 编程语言中，maphash.go 文件中的 flush 函数是一个内部函数，它用于清空哈希状态。

哈希是一种常用的数据结构，它将任意长度的数据映射到固定长度输出的值，这个输出值就是哈希值。在哈希表中，哈希值被用作键，对应的数据被存储在与键相关联的位置上。为了计算哈希值，哈希函数必须遍历整个输入数据，在这个过程中可能会产生一些中间状态。flush 函数就是用来清空这些中间状态的。

具体来说，flush 函数的主要作用如下：

1. 清空哈希状态

函数将链表头、当前链表元素、最后一个键/值对的哈希值等状态变量都重置为初始值，使哈希函数能够从头开始计算下一个键/值对的哈希值。

2. 释放内存

函数还会将当前链表元素从哈希表中删除，并返回其占用的内存。这样可以避免过多的内存占用，提高程序的效率。

3. 处理碰撞

当哈希函数计算出的哈希值与已有键/值对的哈希值相同时，就会发生碰撞。这时，哈希表会将新的键/值对插入到该键/值对的链表中，而 flush 函数将会处理这个链表。具体来说，函数将对链表进行排序，并将具有相同哈希值的键/值对放在同一个链表中，以加快查找速度。

由于哈希函数是每个程序可能都会用到的东西，所以 flush 函数在 Go 编程语言中被广泛使用。但由于其一般作为内部函数使用，因此大多数程序员可能不会直接调用它。
