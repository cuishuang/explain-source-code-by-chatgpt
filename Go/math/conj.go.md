# File: conj.go

conj.go文件是Go语言标准库math中的一个文件，它提供了一个函数ComplexConj，用于计算一个复数的共轭复数。

对于一个复数a+bi，它的共轭复数为a-bi。在数学中，共轭复数的作用在于调整复数的虚部符号。在电学、物理学等领域中，共轭复数则经常被用于表示电流、电压、功率等量中的相位信息。

使用ComplexConj函数可以非常方便地计算任意复数的共轭复数，具体使用方法如下：

```
func main() {
    z := complex(2, -3) // 定义一个复数
    zconj := cmplx.Conj(z) // 计算共轭复数
    fmt.Println(zconj) // 输出 (-3+2i)
}
```

以上代码中，首先使用complex函数创建了一个复数2-3i，然后使用Conj函数计算其共轭复数，并将结果输出到终端上。

总之，conj.go文件提供了一个非常实用的函数来计算任意复数的共轭复数，方便用户在数学、物理等领域中进行计算。

## Functions:

### Conj

在math包中的conj.go文件中，Conj函数的作用是返回给定复数的共轭复数。复数的共轭是将复数中的虚部取反并保持实部不变得到的新复数。

具体来说，Conj的函数签名如下：

```go
func Conj(z complex128) complex128
```

其中，z是一个复数，表示为实部+虚部i的形式。函数返回一个新的复数，其实部与z相同，但虚部取反。

例如，对于一个复数z = 2 + 3i，Conj(z)将返回2 - 3i，这是z的共轭复数。这个函数在处理复数运算时特别有用，比如求两个复数的乘积或除法时需要先将其中一个复数的虚部取反。
