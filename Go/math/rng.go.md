# File: rng.go

rng.go文件是Go语言标准库中math包中的一个文件，它主要实现了一些伪随机数生成器函数，用于生成随机数。

在计算机领域中，随机数生成器通常使用算法来生成随机数。这些算法生成伪随机数，也就是看起来像随机数，但是实际上是根据一组起始值使用特定算法计算出来的。因此，随机数生成器只能用于模拟随机数据，而无法真正生成真正的随机数据。

math包中的rng.go文件实现了两个主要的伪随机数生成器函数，分别是：

- Seed：Seed函数用于初始化随机数生成器。它采用一个int64型的种子作为参数，将种子作为伪随机数生成器的起始值。如果不调用Seed函数，伪随机数生成器的默认起始值为1。
- Uint64：Uint64函数用于生成一个新的64位无符号随机数，该数是根据伪随机数生成算法生成的。它没有参数，每次调用都会生成一个新的随机数。

总之，rng.go文件是Go语言标准库中math包的一部分，实现了伪随机数生成器函数，用于模拟随机数据的生成。

Go语言中的随机数生成器是伪随机数生成器，它并不是真正随机的。但是，它可以产生接近于真正随机数的序列，这种序列称为“伪随机数序列”。随机数生成器的状态作为随机数的种子可以保证每次生成的随机数序列都是唯一的。

总之，rngCooked变量作为随机数生成器的状态，用来保证生成的伪随机数序列的唯一性并且可以使用多种随机数生成算法。

### rngSource

rngSource是一个实现了math/rand.Source接口的结构体。在Go语言中，rand包提供了生成随机数的函数。其中，Source是一个接口，用于生成一系列随机数。rngSource的作用是实现Source接口，提供一些方法来生成随机数。

具体来说，rngSource提供了以下方法：

1. Seed(seed int64)：通过给定的种子来初始化随机数生成器。

2. Int63() int64：生成一个非负的int64随机数。

3. Uint64() uint64：生成一个非负的uint64随机数。

4. Int31() int32：生成一个非负的int32随机数。

5. Uint32() uint32：生成一个非负的uint32随机数。

这些方法通过实现Source接口被rand包调用，用于生成随机数。rngSource可以被其他程序引用，以便于生成随机数序列。



## Functions:

### seedrand

函数`seedrand`用于初始化伪随机数生成器的种子值。伪随机数生成器是计算机程序中常用的一种生成随机数的算法。这种算法实际上是一个确定性算法，它使用一个称为“种子”的输入值作为起点，然后按特定的规则生成一系列的数字，这些数字看起来像是随机的。

在`rng.go`中的`seedrand`函数实际上是调用了内部的`Seed`函数来设置种子。Seed函数将传入的种子值作为输入，然后使用SHA-256哈希函数生成一个伪随机数生成器的内部状态。这个内部状态可以被认为是种子的转换值，它被用来产生一系列随机数。

在实际的使用中，`seedrand`函数通常在程序的启动时被调用，以确保随机数生成器的种子值是随机的。如果种子值是可预测的，那么生成的随机数序列就会变得可预测，因此容易被攻击者利用。为了防止这种情况的发生，种子值通常是从系统时钟、熵池或其他随机源中获取，以确保它们是随机的。在Go中，可以使用`rand.Seed`函数来设置随机数生成器的种子值，该函数实际上会调用`math/rand`包中的`Seed`函数，该函数类似`math`包中的`seedrand`函数，也是用来设置随机数生成器的种子值。



### Seed

Seed是Go语言math包中的一个函数，用于初始化一个伪随机数生成器的状态。伪随机数生成器是通过数学算法计算出的一系列数字，具有看起来随机的特征，但其实是可预测的。

Seed函数接受一个整数参数作为种子值，用于初始化伪随机数生成器的状态。不同的种子值会产生不同的伪随机数序列。我们通常使用当前系统时间作为种子值，以确保每次生成的伪随机数序列不同。

Seed函数只在第一次使用伪随机数生成器时调用一次，之后每次调用rand函数（Go语言math包中的另一个函数，用于生成一个伪随机数）时都会返回一个新的伪随机数。如果使用相同的种子值多次调用rand函数，则每次都会得到相同的伪随机数序列。

Seed函数的作用是确保伪随机数生成器的初始状态是随机的，从而使得生成的伪随机数序列表现出和真正的随机数序列相似的特征。在某些情况下，比如密码学、模拟实验等方面的应用，我们需要使用真正的随机数，此时就不能使用伪随机数。



### Int63

Int63函数是math包中的一个函数，它返回一个非负的64位伪随机整数。伪随机整数是通过伪随机算法计算得到的，虽然不能保证完全随机，但已经足够满足大多数应用场景的需求。

Int63的作用是生成一个随机数，可以用来实现一些需要随机性质的程序，例如游戏、密码生成、随机排列等。同时，Int63生成的随机数分布范围很大，近乎无限，所以可以被认为是很高质量的随机数。

在代码实现中，Int63是通过一个线性同余生成器计算得到的，其计算公式为：

    next = next*0x5deece66d + 0xb

其中，next表示当前状态，0x5deece66d和0xb是常数。此算法是一个非常高效的算法，虽然不能产生真正的随机数，但却可以达到足够高的扰动，从而实现了逼近真正随机数序列的效果。



### Uint64

在go/src/math/rng.go文件中，Uint64函数的作用是返回一个伪随机的64位无符号整数。它采用了一个基于XORshift的伪随机数生成器算法，可以生成高品质的、不可预测的随机数。

具体来说，该算法的实现基于3个不同的64位整数X、Y和Z，并通过一系列位运算和异或操作来生成随机数。由于XORshift算法具有快速、高效、周期大等优点，因此在许多应用领域中都得到广泛的应用。

在实际使用中，Uint64函数通常用于需要随机化的场景，例如密码学、加密、游戏、模拟等，以生成随机、不可预测的数据，提高系统的安全性和可靠性。
