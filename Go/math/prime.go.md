# File: prime.go

prime.go是Go标准库中math包中的一个文件，主要提供了计算质数的函数。

质数是指大于1的整数中，除了1和它本身以外，不能被其他正整数整除的数。比如2、3、5、7等都是质数。

在prime.go中，定义了如下几个函数用于计算质数：

1. func IsPrime(n int) bool

该函数接收一个整数n作为参数，判断n是否是质数。如果是质数，则返回true，否则返回false。

2. func NextPrime(n int) int

该函数接收一个整数n作为参数，返回大于n的下一个质数。

3. func Primes(n int) []int

该函数接收一个整数n作为参数，返回小于等于n的所有质数。

这些函数可以方便地在程序中进行质数的计算和处理。

因此，prime.go是一个非常有用的库文件，可以在Go程序中快速且准确地进行质数计算，应用于各种算法和数学问题中。

## Functions:

### ProbablyPrime

func ProbablyPrime(n int, k int) bool 函数用于判断整数n是否为素数，具体实现是利用Miller-Rabin素性测试算法，该算法的时间复杂度为O(k*log²n)，k为测试的次数。

该算法的基本思想是：如果n是一个素数，那么对于任意一个小于n的整数a，如果a^n mod n不等于a，则n一定是合数；如果a的某个次幂mod n等于a本身，那么就说明n很有可能是素数。

在函数实现中，首先会判断n是否小于2或者是2的倍数，如果是，则直接返回false。然后根据n的值选择不同的探测基数，例如如果n小于不超过160位的最小完全平方数，则选择探测基数为2，3，5，7；如果n不超过2^32，则选择探测基数为2，7，61；如果n不超过2^64，则选择探测基数为2，325，9375，28178，450775，9780504，1795265022。然后就对每个基数进行k次探测，如果都满足上述条件，则将n判断为素数，否则将其判定为合数。

注意该函数只是对n的素性进行了一定的概率估计，并不完全准确。当测试次数k越大，误判为素数的概率就越小，但计算时间也越长。



### probablyPrimeMillerRabin

probablyPrimeMillerRabin函数是一个用于判断一个数是否为素数的算法，采用了Miller-Rabin素性测试算法。其作用是判断一个大整数是否为质数。其实现核心为基于费马小定理，多次做随机选择。该函数最终会返回一个布尔值，true代表传入的数很可能是一个质数，false则表示不是。

具体实现流程如下：
1. 先根据质数规则判断输入的数n是否小于2或是2，3等质数，因为接下来的Miller-Rabin算法无法判断这些超小范围内的质数。
2. 把输入的n减去1，得到n-1。
3. 将n-1分解为2的幂次和奇数c的积：n-1=2^s*c，其中s是一个非负整数，c是一个奇整数。
4. 随机选取一个整数a，满足1 < a < n-1。
5. 计算x = a^c mod n。
6. 如果x等于1或n-1，那么n很可能是一个质数，返回true。
7. 迭代s-1次：如果x等于n-1，那么n很可能是一个质数，返回true；否则，计算 x = x^2 mod n。
8. 如果在以上操作中，都没能找到一个值使得x等于n-1，那说明n不是质数，返回false。

由于随机性的存在，可能有极小的概率出现错误结果，但错误概率非常小，被认为是可以接收的。因此，这个方法使用广泛。



### probablyPrimeLucas

probablyPrimeLucas是math包中prime.go文件里的一个函数，用于检查一个大整数是否是素数，即只能被1和自身整除的整数。它使用了Lucas序列的方法进行判断。

其大致工作步骤如下：

1. 判断输入的整数是否小于等于5，因为小于等于5的整数都是素数。

2. 判断是否能被2、3、5整除，如果可以直接判为合数。

3. 对于大于5的整数n，根据伪素数的定义，如果有一个整数a满足a^(n-1) ≡ 1 (mod n)且a不是n的倍数，则n可能是伪素数，如果不能找到这样的a，则n一定是素数。

4. 对于上一步中找到的a，计算它的阶，即最小的k使得a^k ≡ 1 (mod n)，如果k=n-1，则n是素数，否则n是伪素数。

在检查素数性质时，probablyPrimeLucas还使用了Miller-Rabin算法的迭代次数进行优化，增加判断素数正确性的可靠性。

总之，这个函数的作用是对于输入的大整数进行素数性质的判断，返回一个bool值来表明该整数是不是素数。
