### archFloor

archFloor函数是一个汇编实现的函数，用于将一个float64类型的数字向下取整。具体作用是：

1. 将输入的float64类型数字 x 转换为一个 64 位整型 i

2. 如果 x 是正数，则 i 就是小于等于 x 的最大整数，即 i = floor(x)

3. 如果 x 是负数，则 i 就是大于等于 x 的最大整数，即 i = ceil(x)-1

例如，对于输入的 x = 3.6，archFloor函数将其转换为整数 i = 3。

这个函数之所以被实现为汇编语言，是因为在硬件层面进行浮点数计算速度更快，可以提高代码的执行效率。此外，实现向下取整的汇编代码也更加简单和直观。
