### low32

在go语言的math包中，int.go文件中含有一个名为low32的函数，其作用是将给定的64位整数x的低32位截取出来并返回一个32位整数。

具体地说，该函数通过使用位移与位掩码的方式来实现低32位的截取。具体思路如下：

1. 对于给定的64位整数x，将其右移32位（即舍弃高32位），从而将其低32位移至整数的最高位。

2. 构造一个32位位掩码M，其二进制编码为32个连续的1，即：M = 0xFFFFFFFF。

3. 对于x右移32位后该整数的最高位字，使用与M按位与的方式来取到其低32位数值。这部分的代码实现为：v := int32(uint64(x >> 32) & 0xFFFFFFFF)

4. 将上一步中得到的32位整数v与x的最低32位按位或得到一个新的32位整数值，即：return int32(x)<<32 | v

因此，通过对数值按位移动并进行按位或、按位与操作，low32函数就实现了将64位整数截取其低32位并返回的功能。

### GCD

在math包的int.go文件中，GCD函数用于计算两个整数的最大公约数（Greatest Common Divisor）。最大公约数是指两个数公共的约数中最大的一个，例如12和18的最大公约数为6。GCD函数使用了欧几里得算法（Euclid's algorithm），该算法使用了辗转相除法来进行计算。具体思路如下：

1. 将两个数中较小的数作为被除数，较大的数作为除数，进行相除。

2. 计算出余数，将除数赋值给被除数，将余数赋值给除数。

3. 重复这个过程，直到余数为0为止。此时，最大公约数就是最后一个不为0的余数。

GCD函数的代码如下：

```
func GCD(a, b int) int {
    if b == 0 {
        return a
    }
    return GCD(b, a%b)
}
```

该函数使用了递归的方式来实现欧几里得算法。如果第二个参数b等于0，那么函数直接返回第一个参数a，否则继续调用GCD函数，传入第二个参数b和第一个参数a对第二个参数b取余的结果，直到第二个参数b等于0为止。

GCD函数在数学计算、编程等领域都有广泛的应用，例如在分数的约分、化简等运算中常常要使用到GCD函数。



### lehmerSimulate

该函数接受一个范围，将生成的随机数缩放到该范围内。这是通过对生成的数执行以下步骤来实现的：

2. 生成一个随机数x
3. 缩放x以适应range

因此，`lehmerSimulate`函数可用于在给定范围内生成伪随机整数。

### euclidUpdate

euclidUpdate函数是用于求两个整数的最大公约数的欧几里得算法中的更新函数。它的作用是根据欧几里得算法的原理，通过反复迭代地调用gcd函数来更新a和b的值，直到a等于b或者其中一个数为0为止。

具体地，欧几里得算法的原理是，如果a和b的最大公约数为d，那么有：

d = gcd(a,b) = gcd(b,a%b)

即a和b的最大公约数等于b和a%b的最大公约数。因此，用euclidUpdate函数可以不断地更新a和b的值，并且每次都将b的值更新为a%b的值，直到b等于0为止，此时a的值即为原来a和b的最大公约数。

具体实现上，euclidUpdate函数会先检查b是否为0，如果是则直接返回a的值作为最大公约数；如果不是，则会用b的值更新a和b的值，即将b的值赋给a，同时将a%b的值赋给b，然后再次调用gcd函数进行迭代，直到b等于0为止。



### lehmerGCD

lehmerGCD是一个实现Lehmer算法的函数，用于计算两个整数的最大公约数（GCD）。Lehmer算法是一种针对大整数GCD计算的优化算法。

该算法的核心思想是在每个步骤中选择一个合适的模数（modulus），使用辗转相减法计算（x mod y）的值，然后将结果与另一个数进行比较并用余数更新x和y的值。通过选择合适的模数，可以使得余数的大小尽可能小，并通过避免除法运算的使用来提高算法效率。

详细的算法过程可以分为以下几步：

1. 选择一个合适的模数d（d值通常为某个小质数）和两个整数x和y，其中x>y且y>0。
2. 计算z = x mod d，然后使用辗转相减法计算u = z*y和v = z*x。
3. 计算q = (x - v) / d和r = (u - y) / d。
4. 如果r等于0，则y是GCD；否则，用y取代x，用r取代y，并重新选择一个模数d。
5. 重复上述过程，直到找到两个数的GCD。

该算法比传统的欧几里得算法更快，尤其是对于较大的整数。因此，它通常被用于一些需要大量的GCD计算的领域，如密码学和编码理论。

### ModInverse

ModInverse函数的作用是计算一个整数m对于另一个整数p的模反元素。模反元素是指在同余等式am≡1(mod p)中，a称为m对于p的模反元素。具体来说，如果a是模m的逆元，则a满足以下两个条件：

1. a · m ≡ 1 (mod p)
2. a < p

在ModInverse函数中，使用扩展欧几里得算法来计算模反元素。该算法输入两个非负整数a和b，输出它们的最大公约数g以及x和y，使得ax+by=g。在计算模反元素时，将a设为m，将b设为p，用扩展欧几里得算法计算出x和y，最终返回x的值。

ModInverse函数的使用场景很多，例如在RSA算法中，需要计算模反元素来生成私钥和公钥，以及在计算哈希值时，需要使用模反元素来计算哈希值的模。

总之，modInverse是一个非常有用的函数，它可以帮助我们快速地找到模m下的乘法逆元，解决许多数论问题。



### Jacobi

Jacobi函数是一个计算该整数是否为二次剩余的函数。在数论中，二次剩余是指一个整数除以某个模数后所得到的余数的平方与该模数的余数同号的情况。Jacobi函数用来判断一个整数是否为模数的二次剩余，并返回1、-1或0的结果。其中1表示该整数是一个二次剩余，-1表示该整数不是一个二次剩余，0则表示该整数等于模数。

Jacobi函数的计算方法是基于欧拉准则的。该准则指出，如果p是一个奇素数且a是一个与p互质的整数，那么a^((p-1)/2) = ±1 mod p。当a是一个模p的二次剩余时，a^((p-1)/2) = 1 mod p；当a不是一个模p的二次剩余时，a^((p-1)/2) = -1 mod p。Jacobi函数利用这个准则来计算一个整数是否为模数的二次剩余。

在math/int.go文件中的Jacobi函数采用递归计算的方式，边界条件是当模数为1或2时直接返回结果。否则，利用欧拉准则来计算是否为二次剩余，并递归调用Jacobi函数计算下一步。最终返回计算结果。



### modSqrt3Mod4Prime

总之，该函数的作用就是用来计算3 mod 4的质数的平方根，是一个重要的数学计算函数。

### modSqrtTonelliShanks

modSqrtTonelliShanks是一个实现了Tonelli-Shanks算法的函数，用于计算以模数为底数的平方根。它的作用是解决如下问题：给定一个大的质数p和一个模数b，找到一个数x，使得x² ≡ b (mod p)。这个问题在密码学和数论等领域经常出现。

Tonelli-Shanks算法是一种用于解决模质数下的平方根问题的高效方法。它的具体实现过程可以概括为以下步骤：

1. 对p进行分解，将p-1表示为2^s*d的形式，其中d是奇数，s是一个非负整数；
2. 找到一个二次非剩余c，也就是c² ≡ b (mod p)没有解的c；
3. 计算r和t，使得d = (p-1)/2^s = r*t，其中r是奇数，并且t是2的幂次数；
4. 初始化a为c^t，并计算x和b(mod p)的平方根的初始值，并进入循环；
5. 在每次循环中，如果a(mod p)等于1或者等于b(mod p)，则返回x为结果；
6. 在每次循环中，计算m，使得a^(2^m)(mod p)等于1(mod p)，然后更新x和b(mod p)的平方根的值，并将a更新为a^(2^m)。

最终，当循环结束时，x就是对应的平方根。

总体来说，modSqrtTonelliShanks函数提供了一种可靠和高效的方法来计算模质数下的平方根，可以应用于各种领域，尤其是密码学和数论。

### Lsh

Lsh是一个位运算函数，代表左移操作（left shift）。左移操作是将一个二进制数向左移动指定的位数，空出的位用0补齐。

具体地，Lsh函数接受两个参数：一个int类型的x和一个无符号整数n。它将x的二进制表示向左移动n个二进制位，然后返回结果。例如，如果x = 5（二进制表示为101），n = 3，则Lsh(x, n)的结果为40（二进制表示为101000）。

该函数通常用于对二进制数进行快速乘以2的幂次方操作。例如，如果要将一个整数乘以8，可以使用Lsh(x, 3)的形式，而不是计算8*x的值。

Lsh函数还可以用于实现位掩码（bitmask）功能，即将一个整数的二进制表示中的特定位复制到另一个整数中。例如，如果要将一个整数的最低4位复制到另一个整数的最高4位中，可以使用Lsh(x & 15, 28)的形式，其中&运算表示按位与操作，用于取出x的最低4位。



### Rsh

Rsh是一个函数，用于将一个整数（第一个参数）向右移动指定的位数（第二个参数）。这相当于将整数除以2的幂。函数返回新的整数。

Rsh的作用之一是执行高速算术运算。在某些情况下，将整数向右移动相当于将其除以2的幂，从而避免了乘法和除法的高开销。在高性能计算中，这种技术非常有用。

在Go语言的math包中，Rsh被定义为将一个int64类型的整数向右移动一个uint类型的位数，并返回int64类型的结果。如果移动位数超出了int64类型的最大范围，则函数会返回移位后的值。
