### SetFloat64

SetFloat64是Go语言math库中的一个函数，它的作用是将一个浮点数转换为分数形式。

具体来说，SetFloat64方法会接收一个浮点数作为参数，然后使用最简分数表示法将其转换为一个分数。这个方法的返回值是一个Rat类型的指针，即分数的分子和分母的比例。

这个方法很有用的一个地方是，当我们需要进行分数计算的时候，使用浮点数往往会有精度问题。而使用分数则可以确保计算结果的精度。

以下是SetFloat64方法的具体实现：

```go
func (z *Rat) SetFloat64(f float64) *Rat {
    if math.IsNaN(f) {
        return z.Set(nan)
    }
    if f == 0 {
        return z.Set(zero)
    }
    mant, exp := math.Frexp(math.Abs(f))
    if exp < 0 {
        m := new(big.Int).SetUint64(uint64(mant * (1 << uint(-exp))))
        if f < 0 {
            m.Neg(m)
        }
        return z.SetFrac(m, one)
    }
    num := new(big.Int).SetUint64(uint64(mant * (1 << 53))))
    den := new(big.Int).Lsh(one, uint(exp))
    if f < 0 {
        num.Neg(num)
    }
    return z.SetFrac(num, den)
}
```

该函数的实现采用了一些复杂的计算，用来确保转换出来的分数最简。其中涉及到函数math.Frexp，它用来将一个浮点数拆分成指数和尾数部分，从而方便进行计算。

总之，SetFloat64方法是一个很实用的方法，可以帮助我们在进行分数计算的时候避免精度问题。



### quotToFloat32

在 go/src/math 中的 rat.go 文件中， quotToFloat32 函数的作用是将给定的分数解析为 float32 类型的小数。

具体地说，该函数将分数的分子与分母分别转换为 float32 类型，然后对分子除以分母，得到一个小数。如果分母为 0，则返回 NaN。

函数定义如下：

```
func quotToFloat32(q, r int64) (f float32) {
    if r == 0 {
        // NaN if q >= 0, -NaN if q < 0
        bits := math.Float32bits(1.0)
        if q < 0 {
            bits |= 0x80000000
        }
        return math.Float32frombits(bits)
    }
    f = float32(q) / float32(r)
    if f < 0 {
        f = -f
    }
    return f
}
```

参数 q 和 r 分别表示分数的分子和分母。

例如，当 q=1，r=2 时，该函数返回 0.5，表示分数 1/2 对应的浮点数为 0.5。

该函数主要用于在计算过程中处理分数，并将分数转换为浮点数进行计算。

### Float64

Float64这个func是用来将一个大数转换成浮点数的函数。在Golang中，由于浮点数的精度不是很高，因此当处理较大的数时，需要使用高精度计算。但是在某些情况下，仍然需要将一个大数转换成浮点数进行处理，这时候就可以使用Float64这个函数。

1. 输入参数是一个指向rat.Rat类型的指针，即要转换成浮点数的大数。

3. 该函数会将输入参数转换成十进制数，并进行舍入操作，得到一个近似的浮点数。

该函数的实现流程如下：

1. 首先对输入的大数进行处理，使其符号位为正。
2. 然后将其转换成十进制小数，并进行舍入操作，得到一个近似的浮点数。
3. 最后根据符号位对浮点数进行反转，返回结果。

使用示例：

```
import (
    "math/big"
    "math"
)

func main() {
    // 创建一个大数

    // 输出结果

```

该示例中将101/50这个大数转换成了浮点数，得到了2.02这个近似值。

### Neg

Neg函数是math库中的一个方法，用于计算有理数的相反数（负数）。具体而言，这个函数会将传入的有理数取相反数，即返回一个相反数，例如负数变为正数，正数变为负数。

这个函数有以下特点：

1. 它接收一个有理数r作为参数，并返回r的相反数。

2. 如果r的值为0（即r的分子为0），那么它将返回0。

需要注意的是，Neg函数不会改变原来的有理数，而是返回一个新的有理数。如果希望将原有理数取相反数，可以将Neg函数的返回值赋值回原有理数变量中，例如：

### Inv

### IsInt

### Cmp

在Go语言中，rat.go文件是一个有理数库文件，该文件中的Cmp函数用于比较两个有理数的大小。具体而言，Cmp函数的作用是比较两个有理数x和y的大小，如果x小于y，则返回-1；如果x等于y，则返回0；如果x大于y，则返回1。

Cmp函数的具体实现如下：

```go
func (x *Rat) Cmp(y *Rat) int {
	if x.a.neg != y.a.neg {
		if x.a.neg {
			return -1
		}
		return 1
	}
	switch x.a.neg {
	case false:
		return x.a.abs.Cmp(&y.a.abs)
	default:
		return y.a.abs.Cmp(&x.a.abs)
	}
}
```

首先，该函数通过判断两个有理数的符号是否相同来确定它们的相对大小。如果两个有理数的符号不同，则它们一定不相等，此时如果x的符号为负，则x小于y，否则x大于y。如果两个有理数的符号相同，则需要进一步比较它们的绝对值的大小。如果x和y的符号均为正，则比较它们的分子的大小。如果x的分子小于y的分子，则x小于y，否则x大于y。如果x和y的符号均为负，则比较它们的分母的大小。如果x的分母小于y的分母，则x大于y，否则x小于y。最后，如果x和y相等，则返回0。

总的来说，Cmp函数是一个非常重要的函数，它为有理数的比较提供了基础的支持，使得在使用有理数库时可以方便地比较两个有理数的大小。

### Sub

Sub是一个函数，它用于计算两个Rat类型的值的差。

在Go语言的math包中，Rat类型是一个有理数类型，表示为分数形式，其中分子和分母都是整数。Sub函数接收两个Rat类型的参数，分别表示被减数和减数，返回一个新的Rat类型的值，表示它们的差。

Sub函数的实现如下：

```go
func (x *Rat) Sub(y *Rat) *Rat {
    if x.IsInt() && y.IsInt() {
        return NewInt(x.a - y.a)
    }
    num := new(Int).Set(x.a)
    den := new(Int).Set(x.b)
    num.Mul(num, y.b)
    den.Mul(den, y.a)
    return &Rat{num.Sub(num, den), den}
}
```

首先，如果两个参数都是整数，Sub函数会用NewInt函数将它们的差计算出来，并返回一个新的Rat类型的值，其中分子为差，分母为1。

如果两个参数都不是整数，Sub函数首先对第一个参数的分子和分母进行复制，然后分别乘上第二个参数的分母和分子。然后，使用NewRat函数将分子和分母构造为一个新的Rat类型的值，并返回它。
