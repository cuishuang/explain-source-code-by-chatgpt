# File: lgamma.go

该文件实现了lgamma函数，lgamma函数是伽马函数的对数，即log(Γ(x))。伽马函数是数学中十分重要的一个函数，用于广泛的领域，例如概率论、统计学、数值计算、物理学和工程学。

该文件中的lgamma函数计算Gamma(x)的自然对数，它是一种高精度的函数，能够准确计算在浮点数表示范围内的任意x的LogGamma函数值。该实现在数值计算中被广泛使用，例如在概率分布中计算Beta、Gamma和Chi-Squared分布中的参数。

具体来说，lgamma函数的输入参数是一个浮点数x， 返回值是x的伽马函数的自然对数。它使用一系列方法，包括判断和矩形分解来计算伽马函数的自然对数。

判断方法是通过判断x的符号和整数部分来选择不同的算法求解伽马函数。如果x是负数，则会先使用对称性将负数变为正数，然后计算伽马函数再加上一个符号。如果x是整数，则返回伽马函数的阶乘值的自然对数。如果x是小数，则使用矩形分解方法来计算伽马函数的自然对数。

总之，该文件实现了一个高精度的伽马函数对数计算，为数值计算提供了强有力的支持。

### _lgamR

在go/src/math中的lgamma.go文件中，_lgamR变量是用来存储调和级数的系数的数组。调和级数是指自然数的逆数加和，其公式为：

在计算lngamma函数（伽玛函数的自然对数）时，需要用到调和级数的系数，因为伽玛函数和调和级数之间有一定的联系。

具体来说，lngamma函数可以写成下面的形式：

其中，B_2n是伯努利数，后面的那个无限级数就是调和级数。在计算这个无限级数时，需要用到调和级数的系数。_lgamR变量就是存储这些系数的数组。这个数组是在init函数中初始化的，它的值是预先计算好的，并被保存在一个名为lgamRData的文件中。

因为_lnR只是一些常数，为了避免反复计算，在整个运行期间保持constant性质，定义为只读变量。



### _lgamS

_lgamS是一个包含预先计算好的值的变量，用于在计算自然对数伽马函数（lngamma函数）时加速计算。

在lgamma.go文件中，有如下注释：

```

```

也就是说，_lgamS变量包含了在[2, 10]范围内预先计算好的自然对数伽玛函数的值，用于计算接近这些点的值时加速运算。

举例来说，如果要计算lngamma(3.5)，则可通过以下步骤完成：

1. 计算ln(2π)/2 = 0.918939
2. 判断3.5是否在[2, 10]范围内，由于3.5不在其中，需要通过Stirling公式进行计算。
3. 根据Stirling公式，lngamma(3.5) = ln(√(2π) * (3.5/e)^3.5 * Γ(1-1/3.5) * (1 + R(1/3.5)))，其中R(x)是更高阶小量。
4. 在计算过程中，需要调用Γ(1-1/3.5)的值，由于1-1/3.5 = 0.7143，属于[2, 10]范围，可以通过_lgamS变量直接查询预先计算好的值（_lgamS[5] = 0.572365）。
5. 通过以上步骤，可加速计算lngamma(3.5)的结果。

因此，_lgamS变量在math库中起到了加速计算自然对数伽玛函数的作用。

### sinPi

函数sinPi(x)用于计算正弦函数πx的值，其中π是圆周率，即3.141592653589793。该函数是lgamma函数的辅助函数，用于计算复杂的Gamma函数的值，这些函数在数学和统计学中经常被使用。sinPi函数的主要作用是对给定的x计算sin(πx)的值。具体来说，当x为正偶数时，sin(πx)的值为0；当x为正整数但不是正偶数时，sin(πx)的值为正或负1，具体取决于x的奇偶性；当x为正小数时，sin(πx)的值在-1和1之间波动。

在math中，sinPi函数的具体实现如下：

```
func sinPi(x float64) float64 {
        // Reduce modulo one and then reflect to [-pi/2,pi/2] range.
        z := 1 / x
        if z < 0 {
                z = -z
        }
        n := int64(math.Floor(z))
        z -= float64(n)
        var f float64
        if n&0x1 != 0 {
                z = 1 - z
                f = -1
        } else {
                f = 1
        }
        return f * math.Sin(z*math.Pi)
}
```

此实现首先将参数x减去其最接近的整数n，然后将z反射到[-π/2,π/2]范围内，最后计算sin(πz)的值。如果n是奇数，则将z反转，否则返回z的原始值，并根据n的奇偶性设置正弦函数结果的符号。这样，sinPi函数可以正确的处理所有可能的输入值，并返回正确的sin(pi*x)值。
