# File: normal.go

normal.go文件是Go标准库中math包下的一个文件，它实现了正态分布相关的函数。正态分布又称为高斯分布或者钟形曲线分布，是统计学中最为常见的一种分布，它的概率密度函数为：

f(x) = 1/(σ*sqrt(2π)) * e^(-1/2*(x-μ)^2/σ^2)

其中，μ表示期望（均值），σ表示标准差。

normal.go文件中主要定义了以下函数：

1. NormFloat64：返回以μ为均值，σ为标准差的正态分布的一个随机样本。它使用了Box-Muller变换来生成正态分布的随机数。

2. Erf(x float64) float64：返回x的误差函数值。误差函数是高斯积分的一种形式，它的值域在[-1, 1]之间。

3. Erfc(x float64) float64：返回x的互补误差函数值。互补误差函数定义为1减去误差函数。

4. ErfInv(x float64) float64：返回误差函数的反函数值。

5. ErfcInv(x float64) float64：返回互补误差函数的反函数值。

这些函数在统计学和概率论中经常用到，例如在生成随机数、计算置信区间等方面都有应用。

### wn

在Go语言的math库中，normal.go文件中的wn变量表示标准正态分布的权重值，用于实现Box-Muller转换算法，将一组均匀分布的随机数转换为一组标准正态分布的随机数。

Box-Muller转换算法能够将两个独立且均匀分布的随机数转换为两个独立且标准正态分布的随机数。其中，wn变量是Box-Muller算法的核心部分，用来计算正态分布的概率密度函数。

具体来说，wn变量是一个长度为32的数组，表示标准正态分布的密度函数在一定范围内（[0, 3.9]）的取值数量。这个数组的值是通过数值积分得到的，用于进行概率密度函数的插值计算。在正态分布的计算过程中，可以使用该数组中的值来逼近真实的正态分布函数，加速计算过程。

通过这种方式，wn变量实际上是在优化标准正态分布的计算效率，提高了数值计算的速度和精度。它是Box-Muller算法在实践中得以实施的基础。

### NormFloat64

NormFloat64函数是用来计算一个float64类型的数字的标准化值，常用于计算概率密度函数。其定义如下：

```
func NormFloat64(x, mu, sigma float64) float64 {
    const (
        a = 1 / (math.Sqrt2 * math.Pi)
    )
    z := (x - mu) / sigma
    return a * math.Exp(-(z*z)/2)
}
```

其中x是需要计算标准化值的浮点数，mu和sigma分别是期望值和标准差。函数的返回值是一个介于0和1之间的浮点数，表示x在正态分布中的概率密度。

该函数内部通过z值的计算将x标准化到均值为0，标准差为1的正态分布中。具体而言，z的计算公式如下：

```
z := (x - mu) / sigma
```

其中，z表示标准化后的数值，mu表示期望值，sigma表示标准差。通过该公式计算，将x映射到一个以期望值为中心，标准差为1的正态分布中。然后根据正态分布的概率密度公式计算出该数值在正态分布中所占的概率密度，最终得到该函数的返回值。

总之，NormFloat64函数是用来将一个浮点数标准化到正态分布中，并计算出该数值在正态分布中的概率密度。
