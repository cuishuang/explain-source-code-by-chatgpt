# File: erf.go

erf.go文件是Go语言标准库math中的一个文件，其中包含了计算误差函数（error function）和其互补函数的实现。

误差函数是一个数学函数，通常用于描述高斯分布的统计学特性。具体而言，误差函数定义为：

erf(x) = (2/√π) ∫[0,x] e^(-t^2) dt

其中x是输入参数，e是自然对数的底数，t是积分变量。

误差函数在工程、物理学和数学中有广泛的应用，例如在信号处理、神经网络、统计学等领域中都有应用。

在erf.go文件中，有以下几个函数实现了误差函数和其互补函数的计算：

- Erf(x float64) float64：计算误差函数。
- Erfc(x float64) float64：计算误差函数的互补函数，也即1 - erf(x)。
- Erfcinv(x float64) float64：计算误差函数互补函数的反函数，也即erfcinv(erfc(x)) = x。

这些函数在计算和科学计算中都有广泛的应用，Go语言标准库math中提供了这些常用函数的实现，方便用户进行各种计算和科学研究工作。

### erfc

erfc函数可用于计算正态分布的概率密度函数的补函数。如果x是一个正态分布的随机变量，并且μ和σ是该分布的均值和标准差，则erfc函数可以表示为：
