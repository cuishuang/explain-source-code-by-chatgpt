### ceil

在math包的floor.go文件中，除了floor函数之外还有一个很常用的函数就是ceil函数（英文全称：ceiling function）。Ceil函数的作用是返回不小于x的最小整数，也就是向上取整。

例如，对于输入值3.14，Ceil函数将返回4。常见的应用场景是需要把浮点数转换成整数时，如果直接使用类型转换会导致数据无法精确，使用Ceil函数则可以避免这个问题，并且结果更加准确。

具体实现可以查看代码：

```go
func Ceil(x float64) float64 {
    if x <= 0.0 {
        return math.Trunc(x)
    }
    if x >= 1<<52 {
        return x
    }
    ix := Float64bits(x)
    e := int((ix >> 52) & 0x7ff)
    if e == 0x7ff {
        return x
    }
    y := x
    if ix>>63 != 0 {
        y = -y
    }
    if e > 0x3ff {
        t := 1.0
        for i := 0; i < 52; i++ {
            t *= 0.5
            if y+t > 0.0 {
                y += t
            }
        }
        ix := Float64bits(y)
        ix -= 1 // adjust exponent
        ix &= 0x7fffffffffffffff
        ix |= (ix >> 1) & 0x4000000000000000 // bit 54 = bit 53
        y = Float64frombits(ix)
    }
    if y > x {
        return math.Copysign(y, float64(-1))
    }
    return x
}
```

Ceil函数首先判断x是否小于等于0，如果是则直接返回x的整数部分（也就是向0取整）；然后判断x是否大于等于1<<52（也就是2的52次方），如果是则直接返回x本身。

接下来就需要对x进行处理，可以先取出x的位表示（位存储的是符号位、指数和尾数），然后根据指数的大小分别处理：如果指数大于0x3ff，则需要用一个累乘器t，不断减小t将y向上舍入，直到y大于x为止，最后调整指数和位表示即可得到结果。如果指数小于等于0x3ff，则直接返回x的整数部分，也就是向0取整。

注意，在处理y向上舍入时，需要根据符号位判断y的正负，并使用math的函数进行科学计数法的处理。

综上所述，Ceil函数能够通过精确处理浮点数的位表示，得到正确的向上取整结果，非常实用。



### Trunc

Trunc函数是math包中的一个函数，用于截取指定的浮点数x的整数部分。其签名为：

```go
func Trunc(x float64) float64
```

其中x为要截取整数部分的浮点数，返回值为x的整数部分。

Trunc函数的作用是将浮点数x的小数部分舍去，只保留整数部分，返回一个浮点数类型的结果。举个例子，如果x为3.141592653，那么Trunc(x)的结果就会是3.0。如果x为-2.718281828，则Trunc(x)的结果为-2.0。

Trunc函数的实现比较简单，它是通过将浮点数x转换为整数类型，然后再将其转换回浮点数类型得到结果的。具体的实现代码如下：

```go
func Trunc(x float64) float64 {
    if x < 0 {
        return math.Ceil(x)
    }
    return math.Floor(x)
}
```

这段代码首先判断x是否小于0，如果是，就使用math.Ceil函数将x向上取整；如果不是，就使用math.Floor函数将x向下取整。通过不同的取整函数，实现了对浮点数x的整数部分截取。

总之，Trunc函数可以方便地对浮点数进行整数部分截取，有助于解决一些与整数计算相关的问题。



### trunc

Trunc函数的作用在于将一个浮点数转换为整型数，但是不会将其四舍五入。如果希望将浮点数四舍五入为整型数，应该使用Round函数而不是Trunc函数。



### Round

在go/src/math中，Round函数用于将浮点数四舍五入为最接近其值的整数。

具体而言，Round函数接受一个浮点数f作为输入，并将其四舍五入为最接近f的整数。如果f小于0.5，则返回0；如果f大于或等于0.5，则返回1。

函数签名如下：

```
func Round(f float64) float64
```

举例如下：

```
fmt.Println(math.Round(2.5)) // 输出2
fmt.Println(math.Round(3.5)) // 输出4
```

在数学计算和编程中，Round函数有许多应用场景，比如在计算货币、计算平均数等方面。



### RoundToEven

RoundToEven是一个函数，用于将浮点数四舍五入到最接近的偶数。它位于Go语言标准库中的math包中的floor.go文件中。

具体来说，如果需要四舍五入的数字末位为5，且其前一位为偶数，则该数字将被舍去。如果末位为5，且前一位为奇数，则该数字将被进位。

例如，RoundToEven(2.5)将返回2，而RoundToEven(3.5)将返回4。

这个函数通常用于在进行精确计算时避免舍入误差。因为在数字量较大或数字操作比较频繁的情况下，舍入误差可能会导致计算结果出现较大的偏差。通过使用RoundToEven函数进行四舍五入，最终结果更加准确和可靠。
