# File: indent.go

indent.go文件位于Go语言标准库中的encoding包中，其作用是提供了一个可扩展的缩进功能，可以将结构化数据格式（如JSON，XML等）的内容进行缩进和格式化输出。

具体来说，indent.go文件中定义了一个结构体类型Indent，该类型包含如下字段：

```
type Indent struct {
    Writer  io.Writer // 输出的io.Writer接口
    Prefix  []byte    // 每行前缀的字节序列
    Indent  []byte    // 缩进的字节序列
    HTML    bool      // 是否输出为HTML的标签
    Escape  func(w io.Writer, b []byte) // 转义函数
}
```

其中，Writer是输出的写入目标，Prefix是每行前缀的字节序列，Indent是缩进的字节序列，HTML表示输出的是否是HTML标签，Escape是一个用户提供的可选参数，用于执行转义操作。

通过Indent类型的方法，我们可以对待格式化输出的数据进行格式化和缩进，同时也支持将缩进输出到HTML或其他结构化数据格式。

总的来说，indent.go文件提供了一种方便、快捷的方式对结构化数据进行缩进输出。它可以方便地应用于各种场景，例如打印调试信息、生成机器可读的文本等等。

### HTMLEscape

在go编程语言中，encoding包是用于数据编码和解码的标准包。其中，indent.go文件中的HTMLEscape函数主要用于将HTML转义字符替换为对应的实体引用，以使其能够在HTML文档中正确地显示。

具体来说，HTMLEscape函数将输入参数中的特殊HTML标记字符（如<, >, &, ", '等）替换为其对应的实体引用，如"替换为&quot;，<替换为&lt;，等等。这样可以避免在HTML中使用这些字符时出现意外的解析结果，从而提高文档的可读性和可靠性。

另外，HTMLEscape函数还支持在转义过程中进行缩进的操作，以适应文档的展示需求。它可以根据参数中的前缀字符串对缩进进行控制，将转义后的文本输出成适当的格式。

总之，HTMLEscape函数是一个非常重要的功能，它能够帮助开发者在HTML编码中正确地使用特殊符号，并能够保证文档呈现的效果符合预期。



### appendHTMLEscape

appendHTMLEscape函数是一个帮助函数，用于将文本转义为HTML实体，以便在HTML页面中显示。可以在编码HTML或在输出HTML时使用它。

这个函数主要用于将数据转化为字符串，避免在数据中包含HTML特殊字符而引起解析错误。例如：将“<”字符转换为“&lt;”，将“>”字符转换为“&gt;”，将“&”字符转换为“&amp;”，以及将双引号和单引号转义为相应的实体。

此函数接受两个参数，第一个参数是要附加的字节数组，第二个参数是要进行HTML转义的字符串。它会将转义后的结果附加到第一个参数中，并返回一个新的字节数组。

例如，当我们需要在HTML页面上显示有特殊字符的文本时，可以使用appendHTMLEscape函数将文本转义，如下：

```
var buffer bytes.Buffer
text := "This is an <example> of a &special character"
encodedText := appendHTMLEscape(buffer.Bytes(), text)
```

在上面的代码中，我们定义了一个bytes.Buffer类型的buffer变量，用于存储转义后的文本。然后，我们使用appendHTMLEscape函数将text参数进行转义，并将结果附加到buffer变量中。



### Compact

在Go语言中，encoding包提供了一组编解码的函数，包括将数据转换为JSON、XML以及其他格式。其中，indent.go文件中的Compact函数用于去除JSON数据中的空白字符和换行符，生成一个紧凑的JSON字符串。

具体来说，Compact函数将输入的JSON字符串解析为一个Json对象，并将其重新格式化为一个不包含空白字符的字符串。在重构期间，它保留最小数量的空格缩进，以使解析后的数据具有最紧凑的表现形式。紧凑的JSON格式可以节省空间并更快地传输，尤其适用于大型数据集。

Compact函数的定义如下：

```
func Compact(dst *bytes.Buffer, src []byte) error {
  return CompactOptions(dst, src, &CompactOptions{})
}
```

其中，参数dst是一个bytes.Buffer类型的参数，表示输出的JSON字符串；参数src是一个[]byte类型的参数，表示输入的JSON字符串。Compact函数的返回值为error类型，表示是否出现错误。

在Compact函数内部，它首先使用Json的Unmarshal函数将输入的JSON数据解码为一个Json对象。然后，它使用Json的Marshal函数将解码后的Json对象重新编码为一个紧凑的JSON字符串，输出到输出缓冲区中。最后，它返回一个可空的错误消息，如果出现错误，则返回该消息。



### appendCompact

在encoding/indent.go文件中，appendCompact函数实现了将缩进文本附加到字节片中的功能。它被用于将JSON和XML格式的数据转换成字符串时，可以在输出中添加限定字符，如缩进、新行和空格等，以便于人类阅读数据。具体作用如下：

1. 构建新行和缩进符：如果输入的缩进大于零，则该函数先附加一个换行符('\n')，然后附加适当数量的缩进符(tab)。这样就可以在输出中形成一个新行和缩进格式，以便于阅读。

2. 添加文本内容：函数将输入的文本直接附加到输出的字节片中。这通常是在新行和缩进格式之后的最后一个字符。

3. 调整末尾空格：如果该函数附加的文本以空格结尾，则该函数将从最后一个空格开始计算，将其后的所有空格都替换为空字符('\0')，以便于避免出现尾随空格。

4. 返回新的字节片：最后，该函数返回一个新的字节片，其中包含新的文本和缩进格式。

在编码或解码数据时，appendNewline函数是一种方便的工具，可确保生成的数据保持良好的格式。



### Indent

Indent函数是在编码JSON时使用的。它使用指定的前缀和缩进写入JSON对象。如果给定了前缀和缩进字符，则函数会以给定的字符串为前缀字符串，并在每行后添加缩进字符串。这有助于生成具有层次结构的JSON数据，使其易于阅读和排版。

Indent函数有四个参数：

- dst：表示写入JSON的目标。
- src：表示要编码的JSON源。
- prefix：表示用于每行的前缀字符串。
- indent：表示用于缩进的字符串。

例如，如果传入以下JSON对象：

```
{
    "name": "John",
    "age": 30,
    "city": "New York"
}
```

使用Indent函数，并传递前缀字符串"  "和缩进字符串"\t"作为参数，则函数将生成以下格式的JSON：

```
{
  "name": "John",
  "age": 30,
  "city": "New York"
}
```

在每一行中，前缀字符串"  "被添加到开头，而缩进字符串"\t"被添加到每一级的开头，以形成逐级缩进的JSON数据。

具体来说，appendIndent函数会将指定数量的空格字符（用于缩进）添加到缓冲区中。它需要接收两个参数：缓冲区和缩进级别。缩进级别是指当前要添加的缩进空格数量，它通常是在递归调用序列化函数时计算得出的。

在函数内部，appendIndent会在缓冲区中添加指定数量的空格字符，然后返回更新后的缓冲区。为了提高效率，该函数使用了缓存的空格字符，在多次调用时可以重复使用。

总之，通过为序列化数据添加指定数量的缩进空格，可以提高序列化结果的可读性和格式化程度，使其更易于理解和维护。而这正是appendIndent函数的作用所在。
