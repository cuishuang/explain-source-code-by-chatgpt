# File: stream.go

stream.go是Go语言中encoding包的一个文件，它定义了io.Reader和io.Writer的一些实现，用于可以读取或写入数据的数据流（stream）的编码和解码。在这个文件中，有几个结构体和方法是我们需要关注的：

1. Decoder和Encoder：这两个结构体分别是编码和解码的主体，它们可以将数据流和类型之间进行转换。其中Encoder提供了各种不同的编码格式，如Base64、JSON等；Decoder则可以从各种编码格式中解码数据。

2. NewDecoder和NewEncoder：这些函数可以创建Decoder和Encoder。NewDecoder通常与io.Reader一起使用，用于将数据流从io.Reader中读取并解码；NewEncoder通常与io.Writer一起使用，用于将数据编码并写入io.Writer中。

3. BinaryMarshaler和BinaryUnmarshaler：这些接口定义了可以将自己转换为二进制数据的类型，以及可以从二进制数据中解盒自己的类型。这些接口通常用于在网络上传输数据。

除了以上几个结构体和方法外，stream.go文件中还有一些辅助函数和变量，包括错误类型、常量等，用于更好地处理编码和解码过程中可能出现的各种错误情况。

总的来说，stream.go文件是Go语言encoding包中功能最为丰富的一个文件，它可以支持各种编码格式的数据流解码和编码，并且提供了丰富的函数和接口用于实现这些功能。

### Decoder

Decoder结构体是Golang编码/解码库package encoding中的一个重要组成部分。Decoder是用于解码输入流的结构体，主要用于将二进制数据反序列化成数据结构。

具体来说，Decoder结构体通过实现io.Reader接口，可以从输入流中读取二进制数据，并将其解码为Go语言中的数据类型。Decoder结构体支持多种编解码格式，如JSON、XML、ProtoBuf等，可根据需要选择不同的编解码方式对数据进行解码。

Decoder结构体的主要作用是提供了一个通用的解码器，使得不同的编码格式可以以相同的方式进行解码。这样，无论何种编码格式，我们都可以使用相同的API进行解码。同时，Decoder结构体还提供了许多自定义选项，如解码器缓冲区大小、循环引用处理方式等，可以通过这些选项来满足不同场景下的不同需求。

总之，Decoder结构体是Golang编码/解码库中非常重要的一个组件，它为我们提供了一个强大的解码器，使得我们可以轻松地对不同的编码格式进行解码，并将其转化为Go语言中的数据类型。



### Encoder

在Go语言中，`encoding`包提供了编码和解码数据的功能。在该包中，`stream.go`文件中定义了`Encoder`结构体，主要作用是将数据编码为二进制形式存储或传输。

该结构体包含一个字段`w io.Writer`，表示数据将被写入的目标。`Encoder`结构体中定义了一系列方法，如`Encode`、`EncodeValue`等方法，用于将各种类型的数据编码为二进制形式。

在编码数据时，`Encoder`结构体会对数据进行一些预处理，例如将字符串转换为字节序列、将数字转换为十进制或十六进制表示等。然后将预处理后的数据写入`io.Writer`中。

此外，`Encoder`结构体也支持自定义编码方式，通过实现`Encoder`接口中的`EncoderFunc`方法来实现自定义编码方式。

总之，`Encoder`结构体是`encoding`包中重要的结构体之一，提供了将各种类型的数据编码为二进制形式的功能，并支持自定义编码方式。



### RawMessage

RawMessage类型是一个未解析的JSON对象，并且实现了json.Marshaler和json.Unmarshaler接口。这个类型允许开发者将未解析的JSON数据作为对象存储和序列化。

具体来说，RawMessage结构体允许开发者能够在不对JSON对象进行解析的情况下，对其进行一些转换和修改操作。然后可以通过json.Marshal函数将修改后的未解析的JSON对象序列化为JSON格式的字符串。

使用RawMessage类型时，需要注意以下几点：

1. RawMessage结构体是一个字节切片类型，存储了未解析的JSON数据；
2. 如果将RawMessage结构体作为一个字段添加到结构体中，那么这个字段将会在序列化时被解析为一个JSON对象；
3. 在对RawMessage结构体进行任何转换和修改之前，需要先使用json.Unmarshal()函数对其进行解析，转换为真正的JSON对象；
4. 转换和修改后的RawMessage对象必须是合法的JSON数据。



### Token

Token这个结构体是在encoding包中用来表示解析器返回的一个标记（token）的数据类型。它有两个字段，一个是Type int型，表示标记的类型，另一个是Value interface{}类型，表示标记对应的值。

在解析器中，每次读取到一个标记，就会将标记的类型和值存入一个Token类型的结构体中，然后返回给调用方。调用方根据返回的标记类型和值，进行相应的处理。例如，在JSON解析器中，如果读到了一个键值对的键，解析器就会返回一个Token类型的结构体，Type字段表示键类型，Value字段表示键名称。

Token结构体的作用是将解析过程中读取到的标记封装成一个统一的数据类型，使得解析器与调用方之间可以采用统一的接口进行交互。



### Delim

Delim结构体是编码器（Encoder）的分隔符，用于在编码字节流中标识不同的值。

在编码字节流中，不同类型的值需要进行分隔，以便在解码时将它们正确地解析回来。Delim结构体就是用来表示编码字节流中的分隔符。它包含两个字段：

- b []byte：表示Delim结构体的字节表示形式。默认情况下，分隔符为一个空格符号（0x20）。
- width int：表示每个分隔符的宽度（以字节为单位）。默认情况下，分隔符的宽度为1。

Delim结构体通常会被用于定义不同编码器的分隔符，例如JSON编码器、XML编码器等等。这些编码器都会使用不同的分隔符来标识不同类型的值。在编码时，每次遇到一个新的值时，编码器就会使用相应的分隔符将其与之前的值进行分隔。在解码时，解码器就会识别这些分隔符，并将它们用于将编码字节流中的不同值正确拼接回来。

总之，Delim结构体是一种用于标识编码字节流中不同类型值的分隔符，它在编码与解码过程中都有重要作用。

NewDecoder函数的作用是创建一个解码器，该解码器可以从输入流中读取数据并将其解码为Go数据结构。在创建解码器后，可以调用其Decode方法来读取下一个值并将其解码为Go数据类型。Decode方法返回一个error类型的值，用于指示解码过程中是否发生了错误。

NewDecoder函数实现了Decoder接口，该接口定义了解码器的基本行为。它包括了ReadByte、Read、UnreadByte等方法，用于从输入流中读取数据并将其解码为Go数据类型。同时，它还包括了Token方法，用于解码各种不同类型的数据。

总的来说，NewDecoder函数是在编码和解码过程中非常重要的一个函数，它提供了一个方便的方式来创建一个解码器，并将数据从输入流中读取并解码为Go数据类型。



### UseNumber

在go/src/encoding/stream.go文件中，UseNumber是一个函数，它的作用是将json中的数字类型解析为go中的Number类型而不是默认的float64类型。

简单来说，在json中，所有的数字都是用字符串的形式表示，而在go中，可以表示为int64、uint64、float64等类型。默认情况下，json.Unmarshal()函数会将所有的数字转换为float64类型。但如果我们希望保留json中的数字的精度，那么就可以使用UseNumber函数。

例如，假设我们有以下JSON字符串：

{"age": 25.43, "salary": 5000}

如果我们使用默认的json.Unmarshal()函数进行解析，那么25.43和5000都会被解析成float64类型。但是，如果我们使用UseNumber()函数进行解析，那么25.43和5000就会被解析成JSON Number类型。

在golang中，JSON Number类型对应着big.Rat类型，该类型可以精确表示任何大小的有理数。因此，当我们使用UseNumber()函数进行解析时，可以保留JSON中的数字精度，这对于某些应用程序非常重要。



### DisallowUnknownFields

DisallowUnknownFields函数是一个编码器选项，在编码器使用流式编码协议（例如protocol buffers）时控制其行为。

当这个选项被设置时，编码器会在编码数据时检测是否存在未知字段。如果存在，则会返回一个错误，表示该编码不符合约定，并且不能被解码器正确解码。这可以确保编码器和解码器之间的兼容性，避免出现未知字段，从而减少潜在的错误和问题。

DisallowUnknownFields函数的作用是更好地控制数据的输入和输出，从而提高程序的稳定性和可靠性。



### Decode

Decode函数是一个通用的解码函数，用于从一个字节序列中解码数据，并将解码后的结果存储在v中。Decode函数可以解码各种类型的数据，包括整数、浮点数、字符串、切片、数组、结构体和接口等。

Decode函数的签名如下：

func Decode(data []byte, v interface{}) error

其中，data参数是要解码的字节序列，v参数是解码后的结果存储位置，它必须是一个指向某种类型的指针。

Decode函数会将data中的字节序列解码成一个值，并将其存储在v中。Decode函数首先会判断v的类型，然后根据该类型调用相应的解码函数进行解码。例如，如果v是一个整数类型的指针，Decode函数就会调用DecodeInt函数进行解码。

在解码时，Decode函数使用递归下降的方式解析字节序列。它首先会读取一个字节作为类型标识符，然后根据类型标识符调用相应的解码函数进行解码。如果解码函数需要读取更多的字节，则Decode函数会递归调用自身进行解码，并将解码后的结果存储在相应的位置上。

如果解码过程中发生错误，Decode函数会返回一个解码错误。否则，它会返回nil，表示解码成功。

需要注意的是，Decode函数并不知道要解码的数据的具体结构，它只能依赖于类型标识符和类型解码函数来进行解码。因此，在使用Decode函数解码数据时，必须确保数据和类型的对应关系正确无误，否则会导致解码错误或者解码结果不正确的问题。



### Buffered

该函数的作用是用于检查缓冲器中的字节数，以便确定是否有足够的数据进行解码或编码。此外，可以使用该函数来确定读取或写入缓冲区的最大字节数以避免溢出。

这个函数有一个参数buff，代表缓冲区，返回值是缓冲区中剩余的未读取的字节数。

其中，`e`代表编码器实例，`Encoding`是编码器类型，而`Buffered`则是该类型的方法。

需要注意的是，该函数只能在读取或写入之后被使用。如果在读写之前调用，它将返回一个错误。



### readValue

readValue函数是encoding包中的一个方法，其作用是从输入流中读取一个数据值。该函数可以解析各种类型的数据格式，如整型、浮点型、字符串等，并返回相应的Go语言值。

具体来说，readValue函数先从输入流中读取一个字节，该字节指示了接下来的数据类型。然后根据数据类型读取相应长度的字节并解析为相应的Go语言值，最后返回这个值。

例如，如果读到的是整型数据类型，readValue函数会读取接下来4个字节的数据并将其解析为一个int32类型的值，并返回该值。类似地，如果读到的是字符串类型，函数会读取一个字节指示字符串长度，然后再读取相应长度的字节并将其解析为一个字符串。

总之，readValue函数的作用是解析输入流并返回一个Go语言值，这在编写解析数据格式的程序中非常有用。



### refill

refill函数是用来填充缓冲区的，它的具体作用如下：

1. 在读取数据时，缓冲区中的数据可能会被读取完，这时需要重新从io.Reader中读取数据，并将数据放入缓冲区中。

2. 为了避免在每次读取数据时都调用底层的io.Reader，refill函数会一次性尽可能多地读取数据，并将多余的数据放入缓冲区中，以提高性能。

3. refill函数还会根据剩余的数据和需要读取的数据长度，计算出需要从io.Reader中读取多少数据，并在读取完毕后更新缓冲区的指针和长度。

4. 在解码的过程中，refill函数还会检查数据的完整性，如果缓冲区中的数据不足以完成解码，refill函数会返回一个错误，以提示调用者需要更多的数据。

总之，refill函数的作用是保证缓冲区中始终存在足够的未读取数据，并在必要时从io.Reader中读取更多数据。它是整个解码过程中非常重要的一部分。



### nonSpace

nonSpace函数的作用是查找给定切片中的第一个非空格字符，并返回其索引。如果整个切片都是空格，则返回切片的长度。该函数在编码和解码过程中很常用，因为在某些情况下需要忽略空格字符，比如JSON和XML编码格式中的空格。 

该函数的实现方式很简单，它使用一个for循环遍历输入切片中的每个字符，如果字符不是空格，则返回其索引，否则继续查找下一个字符；如果遍历了整个切片都没有找到非空格字符，则返回切片的长度。在具体的编码和解码逻辑中，程序员可以根据需要对该函数进行灵活的调整，以满足具体的业务需求。



### NewEncoder

NewEncoder是一个函数，用于创建一个新的编码器。

编码器是一种将数据序列化为指定格式（如JSON、XML、Gob等）的工具。它们将数据结构转换为格式化的字节序列，以便于存储和传输。

NewEncoder的作用是创建一个新的编码器，并将其绑定到指定的输出流上。这样，当向编码器写入数据时，数据将被序列化并输出到绑定的输出流中。

具体而言，NewEncoder的参数是一个io.Writer类型的输出流。它返回一个编码器，可以使用此编码器将数据序列化为所选格式并将其写入指定的输出流中。

例如，以下代码片段创建一个JSON编码器，并将其绑定到标准输出流：

```
package main

import (
    "encoding/json"
    "os"
)

func main() {
    encoder := json.NewEncoder(os.Stdout)
    data := map[string]string{"hello": "world"}
    encoder.Encode(data)
}
```

在此示例中，NewEncoder创建了一个新的JSON编码器，将其绑定到os.Stdout，即标准输出流。然后，我们将一个映射数据结构写入编码器，编码器将数据序列化为JSON格式，并将其写入标准输出流中。

总之，NewEncoder是一个非常有用的函数，它允许我们轻松创建编码器并将数据序列化为所需格式。



### Encode

Encode函数是一个通用的编码函数，在将值编码成byte序列时逐个逐个地写入输出流。这个函数支持的数据类型包括布尔类型、整型、浮点型、字符串、列表、字典等。具体作用包括以下几点：

2. 将序列化后的数据写入流中：Encode函数可以将序列化后的数据写入任何输出流（如文件、网络连接等），以便其它程序读取和解码。这样可以使得程序之间的数据传输和存储更加方便和高效。

3. 支持自定义编解码方法：Encode函数支持自定义数据类型的编解码方法，通过实现Encode/Decode方法来控制值的编码和解码过程。这样可以在需要时自由地添加自定义数据类型，拓展编码支持。

总体来说，Encode函数是一个通用的编码函数，在将不同类型的值编码为二进制数据时提供了一种方便和高效的方式。通过使用Encode函数，程序可以将数据序列化为二进制，以便于传输和存储，同时也可以自由地添加自定义数据类型以拓展编码支持。



### SetIndent

SetIndent是一个函数，用于设置编码器的缩进字符串和缩进级别（即每个层次需要缩进多少个空格）。当使用编码器生成JSON或XML等格式的输出时，可以利用该函数来美化输出格式以提高可读性。

该函数的具体用法是：

```
func (e *Encoder) SetIndent(prefix, indent string)
```

其中，prefix是每个层次缩进前缀字符串，如"\t"表示缩进一级时需要用一个制表符；indent是每个层次的缩进空格数，如2表示缩进一级时需要缩进2个空格。

例如，使用以下代码设置JSON编码器的缩进前缀为"\t"，缩进级别为2：

```
enc := json.NewEncoder(file)
enc.SetIndent("\t", "  ")
```

这会将缩进前缀设置为一个制表符，缩进级别设置为2个空格。输出的JSON数据会按照缩进级别进行缩进，从而让输出更易读。

总之，SetIndent函数可以用于自定义编码器的缩进格式，以提高输出的可读性。



### SetEscapeHTML

SetEscapeHTML是encoding包中的func之一，它用于将转义HTML字符的选项设置为true或false。如果设置为true，则在编码过程中将会对HTML字符进行转义，如果设置为false，则不会进行转义。

具体来说，HTML字符包括：&，<，>，'，"这些特殊字符。转义后的字符分别为：&amp;，&lt;，&gt;，&#39;，&quot;。通过将HTML字符转义，可以避免在HTML中出现意外的语法错误或安全隐患。

例如，给定以下字符串：

```golang
s := "<script>alert('Hello World!');</script>"
```

使用encoding包进行编码：

```golang
import "golang.org/x/text/encoding"
import "golang.org/x/text/encoding/htmlindex"

enc, _ := htmlindex.Get("utf-8")
s, _ = encoding.EncodeToString(enc, []byte(s))
fmt.Println(s)
```

如果SetEscapeHTML设置为true，会将s转义为：

```golang
&lt;script&gt;alert(&#39;Hello World!&#39;);&lt;/script&gt;
```

如果SetEscapeHTML设置为false，则不会进行转义：

```golang
<script>alert('Hello World!');</script>
```

因此，SetEscapeHTML的作用是控制encoding包在编码过程中是否对HTML字符进行转义。默认情况下，它的值为true，即会进行转义。



### MarshalJSON

具体来说，当我们将一个Go语言的数据类型作为参数传递给MarshalJSON函数时，该函数会按照JSON规范将该数据类型转换成一个JSON格式的字符串返回。对于不同的Go语言数据类型，它们所生成的JSON格式字符串也不同，MarshalJSON可以自动处理这种转换，使得JSON格式化变得简单易用。

总之，MarshalJSON是Go语言中非常重要的一个函数，在进行数据交换和数据传输时经常用到，能够大大提高程序的开发效率和运行速度。

### tokenPrepareForDecode

函数`tokenPrepareForDecode`的作用是为了准备解码器解码时所需的token，以便编码器产生的字节序列可以正确的解码。它主要的任务是将编码器编码时使用的token与解码器解码时需要的token进行匹配，并对它们进行适当的初始化。

具体来说，`tokenPrepareForDecode`函数做以下几件事：

1. 使用一个 switch 语句来判断编码器所使用的token的类型，并根据其类型来做出相应的处理。

2. 如果编码器所使用的token是 tokenArrayStart 或 tokenObjectStart，那么解码器也需要一个相同类型的token来进行匹配。因此，`tokenPrepareForDecode`函数会创建一个新的token并返回它。

3. 如果编码器所使用的token是非容器类型的token，那么在解码器解码时会使用到类似codec.BasicTypeInfo这样的类型信息。因此，`tokenPrepareForDecode`函数会根据编码器所用的token类型来初始化相应的类型信息。

4. 对于容器类型的token，`tokenPrepareForDecode`函数会为其子元素调用递归调用`tokenPrepareForDecode`函数来准备需要的token。

总而言之，`tokenPrepareForDecode`函数的作用是为编码器和解码器之间建立对应关系，以便解码器能够正确地解码使用编码器产生的字节序列。

func tokenValueAllowed(tok Token, val interface{}) bool

参数tok是期望的JSON令牌类型，参数val是要检查的JSON值。函数返回一个布尔值，指示给定的JSON值是否符合给定的JSON令牌类型。

该函数在JSON编码和解码器中非常重要，因为它确保编码和解码过程中的类型安全性。如果JSON值与JSON令牌类型不匹配，则编码器或解码器将无法正确地读取或写入JSON数据。在实际编码或解码JSON时，我们需要使用此函数来确保正确性。

### Token

Token是一个func，它的作用是将数据流解析为一个Token。Token是一个接口类型，它表示一个从数据流中读取的标记或符号。这个函数的定义为：

```
type Token interface{}
func (dec *Decoder) Token() (Token, error)
```

该函数返回两个值：一个 Token 和一个 error。Token 是一个接口类型，它可以是以下任意类型之一：

- bool
- float64

- []Token
- map[string]Token

如果该函数返回一个特定类型的 Token，那么它将读取下一个标记并将其转换为该类型。如果该函数返回 TokenDelim 类型，它表示读取到了流中的一个标记分隔符。读取下一个标记之前，调用方必须使用相应的类型转换从 Token 接口中提取值。

在解析 JSON 或类似格式的数据时，Token 函数提供了一种更底层和更灵活的方式来处理数据。它使得用户可以逐个解析标记，并根据需要处理每个标记。这在处理大型 JSON 数据集时可以提高性能。同时，Token 函数也可以用于编码数据。编码器调用 Encoder.Token 方法依次生成标记，并将它们写入输出流中。



### tokenError

tokenError 是一个用于向解码器返回一个解析错误的辅助函数，它的作用是生成一个新的 SyntaxError ， 并将其返回给解码器。

当解码器无法识别输入源中的标记(token)时，它将会调用 tokenError 函数，传递一个出错信息和一个当前的解码位置。tokenError 函数将使用这些参数创建一个新的 SyntaxError ，然后将其返回给解码器。

SyntaxError 可用于指示解码器出现的一般错误，例如：不合法的 JSON 字符串、不适用于预期类型的值等。tokenError 函数的主要目的是生成这样的错误并返回给调用者，提示解析器出现了错误，并提供上下文信息以帮助确定解析输入源的位置。

总之，tokenError 是一个用于快速捕捉解析错误并生成错误信息的帮助函数，可以提供详细的错误信息以帮助确定代码中的错误位置，简化调试和修复工作。



### More

More 函数是可以将下一个 n 个 bytes 的读取推迟到未来的函数。它是在 io.Reader 接口上实现的，它将从接口实例的底层 io.Reader 中读取 n 个字节，并将它们保留在缓冲区中。然后，在后续的读取操作中，先从缓冲区中处理已经读取的数据，然后再像常规的流一样读取更多数据。这个函数基本上是一个简单的实用函数，通常用于将一些字节缓冲起来，然后在需要它们的时候再进行处理，这可以减少一些性能问题。



### peek

这个函数通常在解码二进制数据时使用，可以通过预览下一个字节来确定要读取的数据类型。对于某些编码，不同类型的数据有不同的前缀，peek 函数可以使用这些前缀确定要读取的下一个数据类型。

### InputOffset

在go语言的encoding包的stream.go文件中，InputOffset函数用于计算从当前读取位置到reader末尾的字节数。

具体来说，InputOffset函数接受一个参数reader，表示数据流输入源。它首先获取当前位置pos，即使用Tell方法获取reader的当前读取位置。然后，它调用Size方法获取reader的总字节数size。如果返回值大于等于0，则计算思路非常简单，直接返回size减去pos即可。否则，表示reader没有提供Size方法（例如标准输入源os.Stdin），InputOffset方法则需要从pos开始读取直到reader末尾，计算字节数并返回。

这个函数的作用在于，计算还有多少字节需要读取，以便知道可以进行哪些操作。在编码、解码二进制数据时，有时候需要预估还有多少数据没有读取或写入，以便做出合理的决策。因此，InputOffset函数对于流式（streaming）数据处理非常有用。
