# File: binary.go

binary.go是Go语言标准库encoding包中的一个文件，用于支持二进制数据的编码和解码。该文件中定义了BinaryMarshaler和BinaryUnmarshaler两个接口，以及针对基本类型、整数、浮点数、字符串、字节切片等数据类型的编码和解码方法。

具体而言，binary.go中的函数和方法包括：

- Marshal：将数据按照二进制编码格式进行序列化，返回序列化后的字节切片。
- Unmarshal：将二进制编码格式的数据进行反序列化，恢复为原始数据类型，并返回解码后的结果。
- Read：从io.Reader中读取指定字节数的二进制数据，并进行解码。
- Write：将指定数据按照二进制编码格式写入到io.Writer中。
- Varint：对整数进行Varint编码，可以进行可变长度压缩。
- PutUvarint：对非负整数进行无符号整数Varint编码。
- Uvarint：解码无符号整数Varint格式的数据。
- Size：返回数据的编码长度，用于确定需要分配的缓冲区大小。

binary.go主要适用于需要快速高效地进行数据编码和解码的场景，比如网络传输、持久化存储、数据序列化等。它与其他编码格式如JSON、XML等相比，具有更小的序列化后数据体积和更快的编码解码速度。

### LittleEndian

在Go标准库的encoding包中，binary.go文件定义了实现大端（big-endian）和小端（little-endian）字节序的函数。其中，LittleEndian变量是一个字节序（ByteOrder）类型的变量，表示小端序（低位字节排放在前面的序列）。

LittleEndian变量在实现二进制编解码（binary encoding/decoding）时起着重要作用，它通常被用于将多个值打包为二进制数据流，或者将二进制数据流解包成多个值。例如，可以使用LittleEndian的方法将uint16类型的整数从内存中的表示转化为小端字节序的表示，这个方法是LittleEndian.Uint16()。

在Go语言中，默认使用小端序，因此LittleEndian变量也是默认的字节序。但是在某些情况下，比如与外部系统进行数据交换时，需要根据实际情况选择使用大端序或小端序。此时，可以使用encoding包中的函数来实现相应转换。



### BigEndian

在go/src/encoding/binary.go中，BigEndian是一个字节序对象。字节序是指存储多字节数据时，在内存中的存储方式，分为大端序和小端序。

对于多字节数据类型（例如整数、浮点数等），字节序决定了将这些数据类型转换成字节流时的顺序。在大端序中，高位字节存储在低地址处，低位字节存储在高地址处。在小端序中，高位字节存储在高地址处，低位字节存储在低地址处。

在binary.go文件中的BigEndian对象使用大端序来编码和解码多字节数据。这意味着它将高位字节排列在低地址处，低位字节排列在高地址处。因此，在使用BigEndian对象编码和解码数据时，最高有效字节（MSB）将首先写入字节流的最低地址处。

使用BigEndian对象的优点是它与网络协议和标准二进制格式的兼容性很好，这些协议和格式通常使用大端序。这使得使用BigEndian对象对于编写网络应用程序和解析二进制格式数据非常有用。

### ByteOrder

### Uint16

Uint16 func是encoding/binary package中的一个函数，其作用是将一个16位的无符号整数按大端序进行编码，并返回编码后的二进制数据。

具体来说，这个函数的参数是一个16位的无符号整数，它会将这个整数转换成一个长度为2字节的byte数组，并且按照大端序的方式进行字节序列化。如果传入的uint16值为0x1234，那么生成的byte数组的值就是{0x12, 0x34}。

主要应用场景是在网络传输和文件IO中，因为网络传输和文件IO都是按照字节流的方式进行传输的，因此需要使用这种编码方式来确保数据的正确性和兼容性。

除了Uint16，encoding/binary中还有其他的一些类似的函数，比如Uint32、Uint64、Int16、Int32等，它们具有类似的功能，只是对应的整数类型不同。



### PutUint16

PutUint16函数是encoding/binary包中的一个函数，用于将一个uint16类型的值按照大端字节序（big-endian）写入指定的字节切片。它的函数原型为：

```go
func PutUint16(b []byte, v uint16)
```

其中，b是一个字节切片，v是要写入的uint16值。该函数先将v按照大端字节序拆分成两个字节，然后将这两个字节按照大端字节序（即高位字节在前，低位字节在后）写入字节切片b。

PutUint16函数主要用于将一个uint16类型的值编码为字节切片，以便于在网络传输或存储到文件中。在网络传输中，常常要求按照大端字节序发送数据包，因此使用PutUint16函数可以方便地将uint16类型的值转换为大端字节序的字节切片。

举个例子，假设我们有一个uint16类型的值x=0xABCD，我们想将它按照大端字节序写入一个字节切片b中，可以使用如下代码：

```go
x := uint16(0xABCD)
b := make([]byte, 2)
binary.PutUint16(b, x)
fmt.Printf("%X\n", b) // 输出：[AB CD]
```

上述代码中，创建了一个uint16类型的变量x，并将其赋值为0xABCD。然后，创建了一个长度为2的字节切片b，并将x按照大端字节序写入b中。最后，使用fmt.Printf函数将b的内容以十六进制形式输出，得到的结果是[AB CD]，也就是0xABCD按照大端字节序编码后的字节切片。



### AppendUint16

AppendUint16函数是encoding/binary包中的一个函数，其作用是将一个uint16类型的值转换为字节切片并添加到另一个字节切片中。该函数的签名如下：

func AppendUint16(buf []byte, v uint16) []byte

其中，buf参数是需要将转换后的字节切片附加的目标字节切片，v参数是要转换的uint16类型的值。函数会将v转换为一个长度为2的字节切片，并追加到buf的末尾，然后返回新的切片。

在网络通信中，传输的数据都是以二进制形式传输的，而uint16类型占用2个字节，因此需要将其转换为一个长度为2的字节切片后再传输。AppendUint16函数就是方便将uint16类型数据转换为字节切片的一个工具函数，可以方便地追加到目标字节切片中。

例如，下面是将一个uint16类型的值转换为字节切片并附加到另一个字节切片中的代码示例：

```
package main

import (
	"encoding/binary"
	"fmt"
)

func main() {
	buf := []byte{0x01, 0x02, 0x03}
	v := uint16(0x1234)
	buf = binary.AppendUint16(buf, v)
	fmt.Printf("%x", buf)
}
```

输出结果为：

```
0102031234
```

可以看到，原来的buf字节切片末尾追加了长度为2的字节切片，其值为0x1234。



### Uint32

Uint32函数是Go语言中encoding/binary包中的一个函数，其作用是将一个字节切片转换成一个uint32类型的值，并返回它。

具体来说，当本地计算机使用的字节序（即byte order）与网络传输的字节序不同时，需要通过调用该函数来进行字节序的转换。在这种情况下，需要使用网络传输时，可以将网络字节序的数据写入字节切片中，并将此切片传输到其他计算机。然后，在接收端，可以使用该函数将字节切片转换为uint32型的数据。

该函数的函数原型如下：

```
func Uint32(b []byte) uint32
```

Uint32函数接收一个字节切片b作为参数，它将b解析为一个uint32类型的值，并返回该值。需要注意的是，该函数的字节切片b必须至少包含4个字节，否则该函数将会引发运行时错误。

示例：

```go
package main

import (
	"encoding/binary"
	"fmt"
)

func main() {
	byteData := []byte{0x12, 0x34, 0x56, 0x78}
	uintData := binary.BigEndian.Uint32(byteData)
	fmt.Println(uintData) // 输出：305419896
}
```

在上面的示例程序中，我们传入一个长度为4的字节切片byteData，并使用BigEndian字节序将其解析为uint32类型的数据。运行后输出结果为305419896。



### PutUint32

在 encoding 包的 binary.go 文件中，PutUint32 函数的作用是将 uint32 类型的整数值逐字节存储到指定的字节切片中，并以大端字节序的方式存储。

具体来说，该函数接受两个参数：第一个参数是一个切片，代表要存储 uint32 值的位置；第二个参数是要存储的 uint32 值。该函数将 uint32 值拆分成 4 个字节，按照大端字节序（高位在前，低位在后）依次存储到字节切片中的每个位置上。

例如，如果要存储 uint32 值 0x12345678，则该值的四个字节分别为 0x12、0x34、0x56 和 0x78，而这些字节将按照大端字节序的方式存储在指定的字节切片中，也就是先存储 0x12，再存储 0x34，然后是 0x56，最后是 0x78。

PutUint32 函数主要用于将 uint32 值编码为字节序列，在网络传输和存储数据等场景中经常会用到。



### AppendUint32

AppendUint32是一个binary包中的函数，它的作用是将32位无符号整数（uint32）编码为一个长度为4字节的小端序列，并将该序列添加到指定的字节切片中。这个函数通常用于序列化操作，将数据从原始格式转换为二进制流，以便于在网络上传输或者在本地存储。

具体来说，该函数的签名如下：

```go
func AppendUint32(b []byte, v uint32) []byte
```

其中，b是一个初始的字节切片，v是要编码的32位无符号整数。在函数执行完毕后，b会增加4个字节的长度，并包含了编码后的整数序列，该序列由字节切片b的末尾4个字节组成。

该函数的实现非常简单，它首先调用`b = append(b, byte(v), byte(v>>8), byte(v>>16), byte(v>>24))`来将32位整数按照小端序编码，并直接将编码结果添加到原始字节切片的末尾，最后返回更新后的字节切片b即可。



### Uint64

binary.go文件中的Uint64函数是一个编码和解码函数，用于将uint64类型的数据转换为字节序列或从字节序列解码为uint64类型的数据。

具体来说，当我们需要将一个uint64类型的数据编码成字节序列进行传输或存储时，可以使用Uint64函数将其转化为一个8字节的字节序列并返回，这个字节序列可以方便地进行传输或存储。而当我们接收或读取到一个8字节的字节序列时，可以使用此函数将其解码为一个uint64类型的数据。

Uint64函数使用大端字节序进行编码和解码，即高位字节位于前面，低位字节位于后面。例如，对于十进制数字12345678901234567890（0xB029 547A F3E8 D3C2），使用Uint64函数进行编码后，返回的字节序列为[0xB0 0x29 0x54 0x7A 0xF3 0xE8 0xD3 0xC2]。

在进行网络通信或存储二进制数据时，使用编码和解码函数可以方便地将各种数据类型转换为字节数组或反向转换回来，从而方便地进行传输和存储。

### String

在Go语言中，编码和解码是进行数据传输和持久化的重要环节。encoding包提供了标准的数据编码和解码实现，其中binary.go是用于二进制编码和解码的实现文件。

在binary.go中有一个名为String的函数，这个函数的作用是将一个字符串编码成一个字节序列。具体来说，该函数会将字符串按照UTF-8编码为字节序列，并在开头添加一个前缀表示字符串的长度，以便在解码时正确读取字符串。

func String(s string) []byte {
    n := len(s)
    if n == 0 {
        return []byte{0}
    }
    var buf [binary.MaxVarintLen64]byte
    n1 := binary.PutUvarint(buf[:], uint64(n))
    data := make([]byte, n1+len(s))
    copy(data[0:], buf[0:n1])
    copy(data[n1:], []byte(s))
    return data
}

在encode包中使用该函数时，通常是对一些结构体的字段进行编码，包括字符串类型的字段，因为字符串类型的数据在传输或持久化时需要被编码为字节序列。在解码时，需要使用相应的解码函数对字节序列进行还原，以获取原始数据中的字符串值。

### dataSize

dataSize函数用于返回给定类型的值在字节中所占的大小。该函数的参数为一个 reflect.Type 类型的值，该类型表示要检查的数据类型。该函数返回的大小指的是二进制编码后的字节数。 

在 binary 包中，经常需要对某些数据类型进行二进制编码或解码。在进行编解码时，需要知道每个值的字节大小，这样才能正确地进行操作。例如，在编码 uint32 类型的数据时，需要保证该值恰好占用 4 个字节的大小。因此，在编解码的过程中，需要明确每个数据类型所占用的字节数。

dataSize函数主要通过使用 switch 语句实现。根据给定的 reflect.Type 类型，函数会检查该类型是否为 bool、int8、uint8、int16、uint16、int32、uint32、int64、uint64、float32、float64 这些基本类型之一。对于其他类型，函数会递归地调用 reflect.TypeOf 函数，直至找到基本类型为止。最终，函数会返回该类型的字节大小。

下面是该函数的实现代码：

```go
// dataSize returns the number of bytes needed to represent
// v, which must be a variable of any integer or floating point type
// or of type bool.
func dataSize(v reflect.Type) int {
    switch v.Kind() {
    case reflect.Bool:
        return 1
    case reflect.Int8, reflect.Uint8:
        return 1
    case reflect.Int16, reflect.Uint16:
        return 2
    case reflect.Int32, reflect.Uint32, reflect.Float32:
        return 4
    case reflect.Int64, reflect.Uint64, reflect.Float64:
        return 8
    default:
        if v.Kind() == reflect.Array || v.Kind() == reflect.Struct {
            n := 0
            for i, c := 0, v.NumField(); i < c; i++ {
                n += dataSize(v.Field(i).Type)
            }
            return n
        }
        panicf("binary: invalid type %s", v)
        panic("unreachable")
    }
}
``` 

需要注意的是，对于复合类型（如数组和结构体），函数会递归地计算每个成员变量的字节大小，并将它们相加。



### sizeof

### int32

int32是一个函数，它的作用是从slice（切片）b的指定位置读取并返回一个32位有符号整数。该函数的定义如下：

func Int32(b []byte, order ByteOrder) int32

其中，b代表要读取的字节切片，order代表使用的字节序（little endian或big endian）。

该函数的详细介绍如下：

1. 该函数会从字节切片b中指定位置开始读取4个字节，将这4个字节从高位到低位组成一个32位有符号整数；

2. 如果字节序为little endian，则先读取的字节存放在整数的低位（即最后一个字节存放在整数的高8位），否则先读取的字节存放在整数的高位（即第一个字节存放在整数的高8位）；

3. 如果给定的切片b的长度小于4个字节，则会panic；

4. 该函数返回读取的32位有符号整数。

int32函数的作用是在编码和解码时，将字节序列转换为32位有符号整数并对其进行处理。通常用于二进制文件、网络传输等场景，能够快速有效地将大量数据转换为对应的整数格式。



### int64

在编码和解码不同数据类型的过程中，int64函数用于将int64类型的数据编码为字节流（binary.Write）或将字节流解码为int64类型的数据（binary.Read）。

总之，int64函数是编码和解码二进制数据中的常见工具函数之一，简化了将int64类型数据与字节流相互转换的过程。



### value

value函数是用于从一个字节序列中解析出一个Go语言中对应类型的值。具体来说，它会根据传入的字节序，将字节流中的数据解析成对应类型的值，并返回解析后的值和成功解析的字节数。

该函数的参数包括字节序、字节流和解析目标值的指针。其中，字节序参数用来描述字节流中的数据按照哪种字节序进行编码，而字节流则是待解析的二进制数据，目标值的指针则是指向一个Go语言中的值（比如int、float等）的指针，用于存储解析后的结果。同时，函数还会返回成功解析的字节数，以及一个错误值（如果解析失败，则返回非nil错误值）。

value函数的实现使用了反射机制，具体来说，它首先会利用反射中的TypeOf和ValueOf函数获取目标值的类型和值，然后根据类型确定需要解析的字节数，并利用字节序将字节流中的二进制数据解析成目标类型的值。最后，该函数会判断解析后的值是否与目标类型匹配，并通过传入的指针将解析结果写入到目标值中。

总之，value函数的作用是将一个字节流按照指定的字节序解析成一个Go语言中的值，并将结果存储到目标值中。这个函数在序列化和反序列化操作中很常见，例如在网络协议通信、存储数据、进程间通信等领域都有广泛的应用。



### skip

在Go语言中，`encoding/binary`软件包用于在编码和解码二进制数据时进行处理。在该软件包中，`skip`函数是跳过给定数量字节的函数，它的作用是将读取器或写入器的位置向后移动指定数量的字节。

`skip`的函数签名如下：
```Go
func skip(w io.Writer, n int) error
```
其中，`w`是一个写入器（Writer）接口，`n`是跳过的字节数量。

`skip`函数使用`io.CopyN`来跳过给定的字节数。

`skip`函数通常用于跳过一些不需要处理或读取的二进制数据。例如，在从输入流读取二进制数据时，可以使用`skip`函数跳过一些元数据或其他无关紧要的信息。

在编写自己的二进制编解码器时，`skip`函数可以作为一个便捷的辅助函数使用，以帮助跳过需要跳过的字节。



### intDataSize

intDataSize函数的作用是返回给定整数类型（int8、int16、int32、int64、uint8、uint16、uint32和uint64）的大小（以字节为单位）。

在编解码二进制数据时，需要知道将要编码的值的大小，以便为其分配足够的空间。要确定整数类型的大小，intDataSize函数根据类型的名称返回相应的大小。intDataSize函数使用switch语句来遍历可能的情况，并返回适当的大小值。对于不支持的类型，函数返回0。

这个函数在编解码二进制数据时非常有用，因为它能够精确地确定整数类型的大小，以便为其分配正确的存储空间。
